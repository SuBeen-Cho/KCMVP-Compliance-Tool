# GCM-002 KCMVP 인증값 길이

## 판정 기준

KCMVP 검증대상 GCM/GMAC의 인증값 길이는 112~128비트이다. 바이트 단위 API에서는 14~16바이트에 해당한다. 암호화 단계와 복호화 단계에 동일한 프로파일을 적용한다.

NIST SP 800-38D의 일반 GCM 프로파일에서 더 짧은 축약 태그가 허용될 수 있으나, 이를 KCMVP 검증대상 프로파일의 정상값으로 판정하지 않는다.

## 단위 판독

- `*_bits`는 비트로 판독하며 112~128을 허용한다.
- `*_bytes`는 바이트로 판독하며 14~16을 허용한다.
- LEA C API 관례의 `tag_len` 또는 `t_len`은 바이트로 판독한다.
- 단위와 용도를 확정할 수 없는 일반 숫자 상수는 정적 확정 탐지하지 않는다.

## 원문 근거

국가보안기술연구소, 『암호알고리즘 구현안내서 Part 2』, 2024.03, p.27과 p.29에서 GCM 암·복호화 입력의 인증값 길이를 112~128비트로 명시한다.
