## 개요

중요 보안매개변수(SSP, Security-Sensitive Parameters)는 다음으로 구성된다:
- **핵심 보안매개변수(CSP)**: 노출/변경 시 암호모듈 안전성을 크게 저하시키는 정보
  (예: 암호키, 개인키, 패스워드, 난수발생기 내부 상태 등)
- **공개 보안매개변수(PSP)**: 인가되지 않은 변경과 대체로부터 보호되어야 하는 공개 정보

**근거 표준**: KS X ISO/IEC 19790:2015 §7.9 (중요 보안매개변수 관리)

---

## SSP 관리 항목

SSP 관리는 다음 6가지 항목을 포함한다:
1. **생성**: 난수발생기 또는 유도함수를 통해 SSP 생성
2. **합의/전송**: SSP 합의(Agreement) 또는 SSP 전송(Transport) 기능
3. **주입**: 직접적(Direct) 또는 전자적(Electronic) 방법으로 SSP 입력
4. **출력**: SSP를 암호화하여 암호경계 외부로 내보내기
5. **저장**: 비휘발성 메모리 등에 SSP 저장
6. **제로화**: 보호되지 않은 SSP 메모리의 0화

---

## 설계서 SSP 관리 표 작성 방법 (GVI Part 1 §9.3)

기본 및 상세설계서의 SSP 관리 표 형식:

| 분류 | 중요 보안매개변수 | 종류(CSP/PSP) | 생성 | 합의/전송 | 주입 | 출력 | 저장 | 제로화 |
|-----|---------------|-------------|-----|---------|-----|-----|-----|------|
| 블록암호 | ARIA 비밀키 | CSP | ○ | | | | | ○ |
| 블록암호 | LEA 비밀키 | CSP | ○ | | | | | ○ |
| 블록암호 | SEED 비밀키 | CSP | ○ | | | | | ○ |
| 블록암호 | 라운드키 | CSP | | | | | | ○ |
| 난수발생기 | DRBG 내부 상태값 V, C(Key) | CSP | ○ | | | | | ○ |

**작성 규칙**:
- **분류**: 해당 SSP가 속하는 카테고리 (블록암호, 전자서명, 암호모듈관리 등)
- **생성**: 모듈이 난수발생기/유도함수로 해당 SSP를 생성하는 기능이 있으면 체크
- **합의/전송**: SSP 합의 또는 SSP 전송을 통해 상호간 공유하는 기능이 있으면 체크
- **주입**: 암호경계 외부에서 직접/전자적 방법으로 SSP를 입력하는 기능이 있으면 체크
- **출력**: SSP를 암호화하여 암호경계 외부로 내보내는 기능이 있으면 체크
- **저장**: 비휘발성 메모리에 SSP를 저장하는 기능이 있으면 체크
- **제로화**: 사용 완료 후 0화하는 기능이 있으면 체크

---

## CSP 보호 요구사항

CSP는 다음으로부터 보호되어야 한다 (KS X ISO/IEC 19790:2015 §7.9.1):
- 인가되지 않은 **접근**
- 인가되지 않은 **사용**
- 인가되지 않은 **노출**
- 인가되지 않은 **변경**
- 인가되지 않은 **대체**

PSP는 인가되지 않은 **변경과 대체**로부터 보호되어야 한다.

---

## 제로화 요구사항

- 사용이 끝난 모든 SSP에 대해 즉시 제로화를 수행해야 한다
- 함수 반환 전 모든 코드 경로(정상 경로 및 예외 처리 경로)에서 제로화 수행
- 컴파일러 최적화에 의해 제거되지 않는 제로화 함수 사용 필수:
  - `memset_s` (C11), `explicit_bzero` (POSIX), `SecureZeroMemory` (Windows)
- 일반 `memset`은 -O2 이상 최적화 옵션에서 제거될 수 있으므로 KCMVP에서 불인정

---

## SSP 저장 방법 (GVI Part 1 §9.4)

보안수준에 따른 SSP 저장 방법은 비휘발성 메모리 저장 시 다음을 고려해야 한다:
- 암호화된 형태로 저장
- 접근 제어를 통해 보호

---

## 엔트로피 관련 보안정책서 안내 (GVI Part 1 §9.2)

난수발생기(DRBG)의 엔트로피 소스에 관한 내용은 보안정책서에 명세해야 한다:
- 엔트로피 소스의 종류 및 위치(암호경계 내/외)
- 엔트로피 추정값
- 미인증 운영자가 엔트로피를 외부에서 입력할 수 없도록 보호

---

## 소수 생성 방법 (GVI Part 1 §9.1)

전자서명 등에 사용되는 소수(prime number) 생성 시:
- 검증대상 난수발생기를 이용하여 생성해야 함
- 생성 방법을 기본 및 상세설계서에 명세해야 함
