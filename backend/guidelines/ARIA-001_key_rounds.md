# ARIA-001 키 길이별 라운드 수

ARIA는 128비트 블록 암호이며 128, 192, 256비트 키를 각각 12, 14, 16라운드로
처리한다. 이는 16, 24, 32바이트 키에 대응한다. 본 규칙은 소스 코드에 이 대응이
명시되어 있으면서 표준값과 모순되는 경우만 보고한다.

S-box 이름, FO/FE 함수명, 회전 함수명 또는 CK 식별자의 부재는 위반 근거로 삼지
않는다. 비트슬라이스, SIMD, 테이블 결합 또는 외부 라이브러리 위임 구현은 동일한
알고리즘을 다른 구조로 표현할 수 있기 때문이다.

이 문서는 프로젝트 저자가 작성한 검사 해설이며 표준 원문이나 KCMVP 판정을
대체하지 않는다. KISA 페이지는 ARIA를 KCMVP 검증대상으로 열거한다. 키 길이와
라운드 수의 구체적 대응은 Informational RFC 5794 Sections 1.1 및 2.3.1을
교차사양으로 사용한다(확인일: 2026-08-11).

- KISA: <https://seed.kisa.or.kr/kisa/kcmvp/EgovVerification.do>
- RFC 5794: <https://www.rfc-editor.org/rfc/rfc5794.html>

ARIA-002 식별자는 정적 구조 규칙으로 사용하지 않는다. 이 식별자는 RFC 5794
Appendix A의 128/192/256비트 예제 데이터를 실행하는 알려진 정답 시험(KAT) 평가를
가리키도록 예약한다.
