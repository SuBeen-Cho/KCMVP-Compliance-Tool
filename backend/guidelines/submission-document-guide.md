## 개요

KCMVP 검증 신청 시 제출해야 하는 문서 목록:
- **Ⅰ. 기본 및 상세설계서** (본 안내서 주요 대상)
- **Ⅱ. 형상관리문서**
- **Ⅲ. 시험서 (시험결과보고서)**
- 보안정책서
- 소스코드

대상: 보안수준 1 소프트웨어 암호모듈 (소프트웨어 라이브러리 형태)

---

## Ⅰ. 기본 및 상세설계서 — 작성 항목

### 1. 암호모듈 명세 (AS02.xx)

**암호모듈 유형 (AS02.03)**
- 암호모듈 유형: 소프트웨어 암호모듈 (동적 라이브러리 .dll/.so/.dylib)
- 구성 형태: 단일 파일 또는 여러 파일
- 운영환경: OS / CPU 아키텍처

**암호모듈 경계 (AS02.07)**
- 암호경계(Cryptographic Boundary) 내 모든 구성요소 명세
- 소스파일 목록 및 역할
- 암호모듈 기능적 구성요소 다이어그램

**탑재 알고리즘 목록 (AS02.09, AS02.20)**

필수 명세 항목:

| 구분 | 알고리즘 | 핵심 보안매개변수 | 검증대상 | 구현적합성 검증 |
|-----|--------|--------------|--------|-------------|
| 블록암호 | LEA-128/192/256 | 비밀키, 라운드키 | O | KAT, MMT, MCT |
| 블록암호 | ARIA-128/192/256 | 비밀키, 라운드키 | O | KAT, MMT, MCT |
| 운영모드 | CBC, CTR, GCM 등 | IV, 카운터 | O | KAT |
| 해시 | SHA-256/384/512 | 없음 | O | 짧은/긴/임의 메시지 |
| MAC | HMAC(SHA-256) | HMAC 키 | O | 임의 메시지 검증 |
| DRBG | HMAC_DRBG(SHA-256) | 엔트로피, 내부상태 | O | 임의 메시지 |

**비검증대상 알고리즘 (AS02.21)**
- 포함하지 않는 경우 명확히 "비검증대상 암호알고리즘을 포함하지 않는다" 명시

**동작모드 (AS02.19)**
- 검증대상 동작모드로만 운영됨
- 초기화 함수(`모듈명_initialize()`) 자동 호출 구조 명세
- 동작 전 자가시험 → 성공 시 검증대상 동작모드 자동 천이

### 2. 암호모듈 인터페이스 (AS03.xx)

**논리적 인터페이스 5가지 (AS03.01)**:
- **데이터 입력**: 함수 입력 파라미터 (평문, 암호키, IV 등)
- **데이터 출력**: 함수 반환 데이터 (암호문, MAC 값, 난수 등)
- **제어 입력**: API 함수 호출 자체
- **제어 출력**: 서비스 수행 중 다른 서비스 호출
- **상태 출력**: 성공/실패 상태 코드 반환 (표시기)

**API 인터페이스 명세 양식**:

```
함수: int KISA_Cipher_encrypt(...)
데이터 입력: 평문, 암호키, IV
데이터 출력: 암호문
제어 입력: API 호출
상태 출력: KISA_SUCCESS(0x01), KISA_ERROR_INVALID_KEY(0x02), ...
제어 출력: 없음
설명: ...
```

**오류 출력 금지 (AS03.xx)**:
- 동작 전 자가시험 중, 제로화 중, 오류 상태에서 데이터 출력 금지
- 오류 상태에서 제어 출력 인터페이스를 통한 제어 출력 금지

---

### 3. 역할, 서비스 및 인증 (AS04.xx)

**인가된 역할**: 관리자(CO), 사용자(User), (필요 시) 암호 담당자(CO)

**서비스 목록**: 각 역할이 수행 가능한 서비스 명세

| 역할 | 서비스 | 인증 필요 여부 |
|-----|--------|------------|
| 관리자 | 초기화, 자가시험, 제로화 | (보안수준에 따라) |
| 사용자 | 암호화, 복호화, MAC 생성, 난수 생성 | (보안수준에 따라) |

**인증 불필요 서비스 (GVI Part 1 §4.1 참조)**:
보안수준 2 이상에서도 인증 없이 제공 가능한 서비스:
1. 해시 알고리즘 (SHA-2, LSH, SHA-3)
2. DRBG (단, 엔트로피 소스가 암호경계 내에서 생성된 경우)
3. 전자서명 검증
4. 운영자 인증 절차 및 초기화 절차
5. CSP를 변경/노출/대체하지 않는 서비스 (상태 표시, 자가시험 등)

---

### 4. 중요 보안매개변수 관리 (AS09.xx)

**SSP 관리 표** (상세설계서에 포함 필수):

| 분류 | CSP/PSP | 생성 | 합의/전송 | 주입 | 출력 | 저장 | 제로화 |
|-----|--------|-----|---------|-----|-----|-----|------|
| 블록암호 비밀키 | CSP | ○ | | | | | ○ |
| 라운드키 | CSP | | | | | | ○ |
| IV/카운터 | PSP | | | ○ | | | ○ |
| DRBG 내부 상태 (V, Key) | CSP | ○ | | | | | ○ |

**제로화 코드 구현 확인**: 소스코드에서 모든 SSP 사용 후 `memset_s` 또는 `explicit_bzero` 호출 필요

---

### 5. 자가시험 (AS10.xx)

**동작 전 자가시험(Power-On Self-Test) 필수 항목**:
- 각 검증대상 암호알고리즘에 대한 KAT(Known Answer Test)
- 소프트웨어/펌웨어 무결성 검사 (HMAC 또는 전자서명 기반)

**조건부 자가시험**:
- 키 생성 시: 키 쌍 일치 시험 (암호화/복호화 또는 서명/검증)
- 난수발생기 연속출력 시험: 연속적으로 동일한 난수 생성 여부 검사
- 소프트웨어/펌웨어 로드 시: 무결성 검사

**자가시험 실패 처리**:
- 자가시험 실패 시 오류 상태로 전이
- 오류 상태에서 모든 암호 서비스 제공 금지
- 오류 상태 코드 반환 (예: `ERROR_SELFTEST_FAILED`)

## Ⅱ. 형상관리문서 — 작성 항목

- **형상관리 시스템**: 소스코드 관리 도구(Git 등) 및 형상 항목 목록
- **형상항목**: 소스코드, 헤더파일, 테스트코드, 문서
- **형상관리 절차**: 버전 관리, 변경 이력, 승인 절차
- **배포, 설치, 삭제**: 암호모듈 배포 방법, 설치/제거 절차

---

## Ⅲ. 시험서 — 작성 항목

### 암호알고리즘 시험결과 (필수)

각 검증대상 알고리즘에 대한 **구현적합성 검증(CAVP)** 결과:

| 시험 유형 | 대상 알고리즘 | 시험 방법 |
|---------|------------|--------|
| KAT (Known Answer Test) | 블록암호, 해시, HMAC, DRBG | 알려진 정답 비교 |
| MMT (Multi-block Message Test) | 블록암호 운영모드 | 여러 블록 메시지 처리 |
| MCT (Monte Carlo Test) | 블록암호 | 반복 암호화/복호화 |

### 암호모듈 관리 API 시험 결과

- 초기화/자가시험 API 시험
- 오류 상태 전이 시험
- 제로화 API 시험

### 외부 API 오류 출력 시험

- 잘못된 파라미터 입력 시 적절한 오류코드 반환 확인
- 오류 상태에서 데이터 출력이 없음을 확인

---

## 소스코드 제출 요구사항

- 검증대상 암호모듈의 전체 구성요소 소스코드 제출
- 소스코드는 설계서의 인터페이스 명세와 일치해야 함
- 주석, 변수명 등이 설계서의 기술과 일치해야 함
- 자가시험 코드 포함
- 무결성 검증 코드 포함 (HMAC 또는 전자서명 기반)
