# CCM-003 KCMVP 인증값 길이

## 판정 기준

KCMVP 검증대상 CCM의 인증값 길이는 14 또는 16바이트이다. 비트 단위로는 112 또는 128비트에 해당한다. 일반 CCM 표준에서 허용되는 4, 6, 8, 10, 12바이트 태그를 KCMVP 프로파일의 정상값으로 판정하지 않는다.

## 단위 판독

- `*_bits`는 112 또는 128을 허용한다.
- `*_bytes`와 LEA C API 관례의 `tag_len`/`t_len`은 14 또는 16을 허용한다.
- 매크로와 상수를 통해 전달되는 경우에는 실제 숫자값과 단위를 함께 확인한다.

## 원문 근거

국가보안기술연구소, 『암호알고리즘 구현안내서 Part 2』, 2024.03, p.33에서 CCM formatting 파라미터를, p.34에서 암호화 인증값 바이트 길이를 14 또는 16으로 명시한다. p.35는 복호화 입력으로 `Tlen`을 정의하고, p.36은 복호화에서도 14 또는 16바이트를 명시한다.
