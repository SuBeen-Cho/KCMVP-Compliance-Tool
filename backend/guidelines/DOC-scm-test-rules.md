## 형상관리문서 요구사항

**CM-001: 형상항목(CI) 목록**
- 소스코드 파일 전체 목록 (경로, 파일명, 역할)
- 헤더 파일, 빌드 스크립트, 설정 파일 포함
- 각 형상항목의 현재 버전/개정 이력

**CM-002: 버전 관리 절차**
- 버전 관리 도구 명시 (Git, SVN 등)
- 브랜치 전략 및 태그 정책
- 변경 이력 추적 방법

**CM-003: 변경 통제 절차**
- 소스코드 변경 시 검토/승인 절차
- 변경 이력 기록 방법
- 버전 번호 부여 규칙 (Major.Minor.Patch)

**CM-010: 빌드 및 설치 환경**
- 컴파일러 종류 및 버전 (예: GCC 12.x, Clang 15.x)
- 빌드 옵션 및 플래그 (보안 옵션 포함: -fstack-protector, -D_FORTIFY_SOURCE=2 등)
- 의존 라이브러리 목록 및 버전
- 설치 절차 및 검증 방법

## 시험서(시험결과보고서) 요구사항

**TEST-001: 구현적합성 시험 (KAT)**
- Known Answer Test 수행 결과
- 각 알고리즘별 KAT 벡터 및 통과 여부
- 필수 대상: LEA, ARIA, SEED, HIGHT, SHA-2, HMAC, DRBG

**TEST-002: 알고리즘 시험 결과**
- Multi-block Message Test(MMT) 결과
- Monte Carlo Test(MCT) 결과
- 시험 도구 및 환경 명세

**TEST-003: 자가시험 결과**
- 전원 투입 자가시험 수행 결과
- 조건부 자가시험 수행 결과
- 시험 통과/실패 처리 로그

**TEST-010: 오류 처리 시험**
- 오류 조건별 오류 출력 확인
- 오류 상태에서의 제로화 동작 확인
- 비정상 입력에 대한 방어 처리 확인

**TEST-020: 타이밍 공격 방지 시험**
- 상수 시간 구현 여부 검증
- 분기문 제거 확인 (키/데이터 의존 분기 없음)
- 캐시 타이밍 공격 방지 구현 확인

## 공통 요구사항

**제출물 버전 일치성**
- 설계서, 형상관리문서, 시험서, 소스코드의 버전이 모두 일치해야 함
- 버전 불일치 시 검증 신청 반려

**시험 환경 명세**
- 시험 수행 OS 및 버전
- 컴파일러 및 빌드 환경
- 시험 장비 사양
