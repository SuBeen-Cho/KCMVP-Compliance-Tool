# Third-Party References

This project references the following standards and guidelines for its
rule definitions and validation logic:

- KS X ISO/IEC 19790:2015 (암호모듈 보안 요구사항)
- KS X ISO/IEC 24759:2015 (암호모듈 시험 요구사항)
- KCMVP 암호모듈 구현 안내서 (GVI Part 1, Part 2) — 한국인터넷진흥원(KISA)
- KCMVP 암호모듈 제출물 작성 안내서 — 한국인터넷진흥원(KISA)
- 블록암호 LEA 규격서 (KS X 3246)

These documents are publicly available from KISA (https://seed.kisa.or.kr).
The rule definitions in this repository are independently authored
interpretations, not copies of the original documents.
