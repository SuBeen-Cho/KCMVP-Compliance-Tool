# [AS04.06] 암호모듈 사용자 역할에 대한 명세

## 1. 보안요구사항 개요
암호모듈의 핵심 기능인 암호 서비스를 이용하는 '일반 사용자' 역할을 정의하고, 해당 역할이 접근 가능한 기본 보안 서비스(암복호화, 해시 등)의 범위를 상세설계서에 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE04.06.01**: 암호모듈 사용자와 연관된 서비스 명세

## 3. 작성 예시 (Examples)

### 3.1. 서술형 예시
"KISACrypto V1.0은 일반 사용자 역할을 지원한다. 암호 사용자는 암호모듈에서 제공하는 기본 보안 서비스를 사용할 수 있다. KISACrypto V1.0이 일반 사용자에게 제공하는 일반 보안 서비스는 블록암호, 해시함수, 메시지 인증코드, 난수발생기, 공개키 암호이다. 또한, 암호모듈에 대한 현재 상태 확인, 그리고 버전 정보 출력도 일반 보안 서비스에 포함된다."

### 3.2. [표] 일반 사용자 가용 서비스 목록
| 서비스 분류 | 상세 서비스 항목 | 비고 |
| :--- | :--- | :--- |
| **암호 연산** | 블록암호(SEED), 해시(SHA-256), 메시지인증(HMAC), 공개키(RSA/DH) | 검증대상 알고리즘 |
| **난수 생성** | HMAC_DRBG 기반 난수 생성 | 검증대상 알고리즘 |
| **정보 조회** | 현재 상태 확인(getState), 버전 정보 출력(getVersion) | 일반 서비스 |

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [사용자 애플리케이션 실행] → [암호 서비스 API 호출] → [사용자 권한 확인(암호 연산/조회 권한)] → [연산 결과 반환]


## 5. 해설 및 증빙 가이드 (Guide)
- **명확한 서비스 매핑**: 사용자가 수행하는 역할과 해당 인터페이스(제어 입력, 데이터 입력, 데이터 출력, 상태 출력) 간의 관계를 명확히 명세해야 함.
- **관리자 역할과의 차별점**: 관리자(AS04.05)만 수행할 수 있는 설치, 초기화, 파기 등의 '관리 서비스'에는 일반 사용자가 접근할 수 없음을 논리적으로 증명해야 함.
- **AS04.11과의 연관성**: 본 항목에서는 역할별 가용 서비스를 개괄적으로 나열하고, 각 서비스에 대한 상세한 입출력 명세는 **AS04.11** 항목에서 기술하여 문서 간의 위계를 맞추는 것이 좋음.
