# [AS04.15] 동작 전 자가시험 서비스 명세

## 1. 보안요구사항 개요
암호모듈 초기화 시 또는 운영자의 요청 시, 모듈의 무결성과 주요 암호 알고리즘의 정상 동작 여부를 확인하는 자가시험 서비스를 정의해야 함. 시험 실패 시에는 즉각 서비스를 차단하고 오류 상태로 천이되는 메커니즘을 포함해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE04.15.01**: 사용자가 호출할 수 있는 자가시험 서비스 명세

## 3. 작성 예시 (Examples)

### 3.1. 자가시험 서비스 개요
"KISACrypto V1.0은 `KISA_Crypto_integritytest()`와 `KISA_Crypto_selftest()` API를 통해 사용자가 동작 전 자가시험을 수행할 수 있도록 한다. 본 서비스는 모듈 초기화 시 자동으로 호출되도록 설계되었으며, 크게 '소프트웨어 무결성 시험'과 '핵심기능 시험(KAT)'으로 구성된다."

### 3.2. 자가시험 구성 항목
- **소프트웨어 무결성 시험**: HMAC 알고리즘을 사용하여 모듈 파일의 변조 여부를 검사함.
- **핵심기능 시험 (KAT)**: 탑재된 알고리즘(SEED, ARIA, SHA-256, HMAC, Hash_DRBG 등)에 대해 기정의된 입출력 값을 대조하여 정상 동작 여부를 검사함.

### 3.3. 실행 결과 로그 예시 (정상 작동)
```text
암호모듈 상태: 000003E8 (LOAD)
KCMVP_Initialize() 호출

[HMAC KAT Test] 1
[Software Integrity Test] 1
[ARIA KAT Test] 1
[DRBG KAT Test] 1

KCMVP 암호모듈 초기화 결과: 1
암호모듈 상태: 000003EA (NORMAL)
```
*결과값 '1'은 시험 성공을 의미하며, 성공 시 검증대상 동작모드(NORMAL)로 자동 천이됨.*

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [초기화 API 호출] → [무결성 시험 수행] → [알고리즘별 KAT 수행] → [성공 시 NORMAL 상태 천이 / 실패 시 CRITICAL_ERROR 상태 천이]

## 5. 해설 및 증빙 가이드 (Guide)
- **시험 결과의 기록**: 본 항목에서 명세한 자가시험 수행 결과와 로그는 향후 제출할 **'암호모듈 시험서'**의 결과와 일치해야 함.
- **실패 시 대응**: 자가시험 실패 시 모듈은 반드시 심각한 오류 상태(`0x000003ED`)로 천이되어 모든 암호 서비스를 차단해야 하며, 이를 복구하기 위한 관리자 조치(재시작/재설치)를 안내서에 포함해야 함.
- **온디맨드(On-demand) 지원**: 초기화 시 자동 실행 외에도, 검증대상 동작모드 운영 중에 사용자가 필요에 따라 수동으로 API를 호출하여 자가시험을 수행할 수 있는 기능을 보장해야 함.
- **알고리즘 전수 검사**: 모듈에 탑재된 모든 검증대상 알고리즘은 사용되기 전 반드시 KAT 형태의 자가시험을 거쳐야 함을 설계 근거로 제시할 것.
