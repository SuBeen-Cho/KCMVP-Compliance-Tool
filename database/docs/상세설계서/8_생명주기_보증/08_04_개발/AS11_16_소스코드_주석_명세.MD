# [AS11.16] 소스코드 주석 명세

## 1. 보안요구사항 개요
암호모듈을 구성하는 모든 소스코드에 대하여 설계 문서와의 일치함을 증빙할 수 있도록 적절한 주석을 작성해야 하며, 모든 구성요소와 주석이 포함된 소스 목록을 제공해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE11.16.01**: 소스코드 주석 작성을 통해 암호모듈의 설계와 일치함을 증명
- **VE11.16.02**: 모든 구성요소와 주석이 있는 소스 목록을 제공

## 3. 작성 예시 (Examples)

| 구분 | 주석 포함 내용 |
| :--- | :--- |
| **파일 헤더** | 파일명, 목적, 작성자, 생성일, 수정 이력, 관련 보안 요구사항 ID |
| **함수(API) 정의** | 함수명, 기능 설명, 매개변수 식별(In/Out), 반환값 의미, 호출 전제 조건 |
| **보안 로직** | 자가시험 호출 지점, CSP 제로화 절차, 오류 처리 및 상태 전이 로직에 대한 설명 |

## 5. 해설 및 증빙 가이드 (Guide)
- **설계-코드 추적성**: 주석 내에 해당 코드가 설계서의 어떤 항목(예: AS09.xx)을 만족시키기 위한 것인지 명시(Traceability tag)하면 심사 시 설계 일치성 증빙이 매우 수월해짐.
- **주석의 수준**: 단순히 "A 변수에 1을 더함" 식의 설명보다는, "설계서의 9.3절 단계 1에 따른 라운드 함수 수행"과 같이 설계서의 문구를 인용하여 작성할 것.
- **PQC 구현 고려**: **HAETAE**와 같이 수학적 복잡도가 높은 알고리즘은 샘플링 과정이나 다항식 연산 시 설계서에 정의된 수식이 소스코드의 어떤 루프와 매칭되는지 주석으로 상세히 설명해야 함.
