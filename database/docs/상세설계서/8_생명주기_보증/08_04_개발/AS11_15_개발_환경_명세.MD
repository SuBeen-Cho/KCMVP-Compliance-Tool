# [AS11.15] 개발 환경 명세 (컴파일러, 옵션 등)

## 1. 보안요구사항 개요
암호모듈의 무결성과 보안성을 보장하기 위해 개발에 사용된 하드웨어, 운영체제, 컴파일러, 링커 및 빌드 옵션 등 전체 개발 환경에 대한 상세 정보를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE11.15.01**: 개발환경(컴파일러, 링커, 런타임 라이브러리 등)에 대한 상세 정보 명세

## 3. 작성 예시 (Examples)

### 3.1. 운영 환경별 개발 도구 명세
"KISACrypto V1.0 암호모듈은 윈도우와 리눅스 환경에서 각각 최적화된 도구를 사용하여 빌드되었으며, 상세 사양은 다음과 같다."

| 구분 | Windows 환경 | Linux 환경 |
| :--- | :--- | :--- |
| **운영체제** | Windows 10 (32/64-bit) | Ubuntu Linux 24.04 (64-bit) |
| **컴파일러** | Visual Studio 2019 (v16.7.5) | GCC 9.3.0 |
| **빌드 도구** | MSBuild (Release Mode) | GNU Make (Makefile 정의) |
| **주요 옵션** | Default Release Optimization | `-fPIC`, `-O3` (최적화 옵션) |
| **생성 파일** | `KISACrypto32.dll`, `KISACrypto64.dll` | `libKISACrypto64.so` |

### 3.2. 리눅스 환경 빌드 상세 (Makefile)
"리눅스 환경에서는 `make` 유틸리티를 사용하며, 공유 라이브러리 형태의 빌드를 위해 `-fPIC` 옵션을 적용하고 성능 극대화를 위해 `-O3` 최적화 옵션을 부여하였다."

## 4. 해설 및 증빙 가이드 (Guide)
- **재현성 확보**: 본 항목의 목적은 제3자가 동일한 소스코드와 환경 설정을 가지고 빌드했을 때 비트 단위로 동일한(Deterministic build) 암호모듈 바이너리가 생성됨을 보장하는 데 있음.
- **Makefile 인용**: 리눅스나 유닉스 계열 환경의 경우, 상세 빌드 옵션을 본문에 모두 적기보다 실제 사용된 `Makefile`의 내용을 별첨하거나 주요 변수(CFLAGS, LDFLAGS 등)를 인용하여 기술하는 것이 효과적임.
- **ARM Cortex-M4 등 임베디드 고려**: 수빈님이 연구 중인 임베디드 환경(Cortex-M4 등)에서는 컴파일러(예: ARM GCC)의 버전뿐만 아니라 사용된 **Target SDK 버전, 링커 스크립트(.ld), FPU 사용 여부** 등의 옵션이 보안 성능에 큰 영향을 미치므로 이를 누락 없이 명세해야 함.
- **PQC 라이브러리 연계**: 양자 내성 암호(PQC) 구현 시 특정 하드웨어 가속 옵션이나 메모리 정렬(Alignment) 옵션을 사용했다면 해당 내용도 함께 명시할 것.
