# [AS11.38] 관리자 안내서 제공

## 1. 보안요구사항 개요
암호모듈을 도입하여 운영하는 기관의 관리자가 모듈을 안전하게 관리하고 운영할 수 있도록 필요한 지침과 정보를 포함한 관리자 안내서를 제작하여 제공해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE11.38.01**: 관리자 안내서 제공
- **VE11.38.02**: 관리자 안내서 제공

## 3. 작성 예시 (Examples)
"본 암호모듈은 도입 기관의 관리자가 모듈을 안전하게 관리하고 운영할 수 있도록 독립된 형태의 **'관리자 안내서'**를 개발하여 제공한다. 해당 안내서는 모듈의 설치부터 운영, 폐기 단계까지 관리자가 수행해야 할 보안 절차를 상세히 서술한다."

## 4. 상세 명세 항목 (Specification)
관리자 안내서는 표준 요구사항에 따라 다음과 같은 핵심 항목들을 포함하여 구성함.

| 주요 명세 항목 | 세부 내용 |
| :--- | :--- |
| **관리 기능 및 이벤트** | 암호 관리자 및 각 역할별로 수행 가능한 관리 기능, 보안 이벤트 정의 |
| **보안 매개변수 명세** | 운영에 사용되는 보안 매개변수(SSP)의 종류, 설정 방법 및 유효한 매개변수값 |
| **인터페이스 설명** | 암호모듈의 물리적 포트와 논리적 인터페이스에 대한 상세 설명 |
| **인증 독립성 유지** | 독립된 운영자 인증 메커니즘이 기능적으로 상호 간섭 없이 독립성을 유지하기 위해 요구되는 절차 |
| **검증대상 동작모드 관리** | 검증대상 동작모드(Approved Mode)에서 암호모듈을 관리하고 상태를 확인하는 구체적 방법 |
| **운영 가정 사항** | 암호모듈의 안전한 운영과 관련하여 전제되어야 하는 사용자의 동작 및 환경에 대한 가정 사항 |

## 5. 해설 및 증빙 가이드 (Guide)
- **문서의 목적성**: 관리자 안내서는 실제 운영자가 참고하는 문서이므로, 기술적인 구현 상세보다는 '어떻게 설정하고 운영해야 보안이 유지되는가'에 초점을 맞추어 작성해야 함.
- **역할 분립**: 암호 관리자(Crypto Officer)와 다른 관리자 역할이 분리되어 있다면, 각 역할이 접근 가능한 기능과 권한을 명확히 구분하여 명세할 것.
- **보안 설정 가이드**: 기본 설정(Default)에서 보안 강화를 위해 변경해야 할 설정값이 있다면 이를 강조하여 표기해야 함.
- **설계서와의 정합성**: 안내서에 기술된 관리 기능과 인터페이스는 본 상세설계서의 인터페이스(AS03) 및 서비스(AS09) 섹션의 내용과 완벽히 일치해야 함.
