# [AS11.08] 유한상태모델(FSM) 명세

## 1. 보안요구사항 개요
암호모듈이 가질 수 있는 모든 상태(State)와 상태 간의 전이(Transition) 조건을 정의한 유한상태모델(상태천이도 및 상태천이표)을 명세하고, 각 상태 전이가 암호모듈 인터페이스와 논리적으로 연관되어 있음을 입증해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE11.08.01**: 암호모듈에 대한 유한상태모델(상태천이도, 상태천이표) 명세
- **VE11.08.02**: 유한상태천이도가 암호모듈 인터페이스와 연관이 있음을 명세

## 3. 암호모듈 상태 설명 (State Descriptions)

| 번호 | 상태 | 설명 (입력/이벤트) |
| :--- | :--- | :--- |
| **1** | **전원 꺼짐** | 암호모듈이 메모리에 로딩되지 않은 물리적 정지 상태 |
| **2** | **전원 켜짐** | 응용 프로그램이 실행되어 모듈 파일이 메모리에 로드된 상태 |
| **3** | **초기화** | 응용 프로그램이 모듈 초기화 API를 호출하여 자원을 할당하는 상태 |
| **4** | **동작 전 자가시험** | 모듈이 사용 전 무결성 및 알고리즘 KAT를 수행하는 상태 |
| **5** | **검증대상 동작** | 자가시험 통과 후 운영자에게 암호 서비스를 제공할 수 있는 정상 상태 |
| **6** | **조건부 자가시험** | 서비스 수행 중 특정 이벤트(키 생성 등)에 의해 추가 시험을 수행하는 상태 |
| **7** | **오류** | 운영자의 단순 실수 등으로 인해 일시적인 오류가 발생한 상태 (자동 복구 가능) |
| **8** | **심각한 오류** | 자가시험 실패 등 모듈의 안전성에 결함이 발견된 상태 (사용자 개입 필요) |

## 4. 상태천이도 및 상태천이표 (Transitions)

### 4.1. 상태천이도 (State Transition Diagram)
암호모듈은 '전원 켜짐' 및 '초기화'를 거쳐 반드시 '동작 전 자가시험'을 성공해야만 서비스 상태로 진입할 수 있도록 설계됨. 자가시험 실패 시 즉각 '심각한 오류' 상태로 격리됨.

### 4.2. 상태천이표 (State Transition Table)

| 번호 | 현재 상태 | 입력(이벤트) | 출력 | 다음 상태 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 전원 꺼짐 | 암호모듈 로드 | 출력 없음 | 전원 켜짐 |
| 2 | 전원 켜짐 | 자동 천이 (초기화 API 수행) | 출력 없음 | 초기화 |
| 3 | 초기화 | 자동 천이 (실패 시) | 수행 결과(실패) | 전원 꺼짐 |
| 4 | 초기화 | 자동 천이 (성공 시) | 출력 없음 | 동작 전 자가시험 |
| 5 | 동작 전 자가시험 | 자동 천이 (실패 시) | 수행 결과(실패) | 심각한 오류 |
| 6 | 동작 전 자가시험 | 자동 천이 (성공 시) | 수행 결과(성공) | 검증대상 동작모드 |
| 7 | 검증대상 동작모드 | 주기적 자가시험 API 호출 | 출력 없음 | 동작 전 자가시험 |
| 8 | 검증대상 동작모드 | 자동 천이 (조건부 자가시험 발생) | 출력 없음 | 조건부 자가시험 |
| 9 | 검증대상 동작모드 | 자동 천이 (단순 오류 발생) | 수행 결과(실패) | 오류 |
| 10 | 검증대상 동작모드 | 자동 천이 (심각한 오류 발생) | 수행 결과(실패) | 심각한 오류 |
| 11 | 조건부 자가시험 | 자동 천이 (실패 시) | 수행 결과(실패) | 심각한 오류 |
| 12 | 조건부 자가시험 | 자동 천이 (성공 시) | 출력 없음 | 검증대상 동작모드 |
| 13 | 오류 | 자동 천이 | 수행 결과(실패) | 검증대상 동작모드 |
| 14 | 심각한 오류 | 종료 API 호출 또는 프로세스 종료 | 출력 없음 | 전원 꺼짐 |

## 5. 해설 및 증빙 가이드 (Guide)
- **인터페이스 연관성**: 모든 상태 전이는 암호모듈의 외부 인터페이스(API) 또는 내부 제어 흐름과 직결되어야 함. 예를 들어, `KISA_Crypto_Init()` 호출은 초기화 상태로의 전이를, 자가시험 실패 리턴값은 심각한 오류 상태로의 전이를 의미함.
- **자동 천이와 일반 천이**: 운영자가 API를 명시적으로 호출하여 바뀌는 '일반 천이'와 모듈 내부 로직에 의해 자동으로 바뀌는 '자동 천이'를 구분하여 기술해야 함.
- **심각한 오류의 불가역성**: 심각한 오류 상태(State 8)에서는 어떠한 암호 서비스도 수행되지 않아야 하며, 오직 '전원 꺼짐'을 통한 재시작만이 유일한 탈출 경로임을 명시하여 보안성을 강조할 것.
- **PQC/LEA 설계 반영**: 구현 중인 암호 알고리즘의 KAT 실패가 곧바로 상태 5에서 상태 8로 이어지는 'Fail-Safe' 로직이 유한상태모델에 정확히 투영되어 있는지 확인할 것.
