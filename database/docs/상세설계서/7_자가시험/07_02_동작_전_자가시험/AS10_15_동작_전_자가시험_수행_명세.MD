# [AS10.15] 동작 전 자가시험 수행 명세

## 1. 보안요구사항 개요
암호모듈의 초기화 과정에서 소프트웨어 무결성 및 탑재된 암호 알고리즘의 정상 동작 여부를 확인하기 위한 동작 전 자가시험(Pre-operational Self-test)의 수행 절차와 관련 정보를 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.15.01**: 설계서에 동작 전 자가시험에 대한 정보 명세
- **VE10.15.02**: 자가시험의 구체적인 수행 항목 및 절차 명세

## 3. 작성 예시 (Examples)

### 3.1. 동작 전 자가시험 개요 및 수행 순서
"본 암호모듈은 시스템 라이브러리 로드 시 또는 초기화 API 호출 시 동작 전 자가시험을 자동으로 수행한다. 자가시험은 크게 소프트웨어 무결성 시험과 핵심기능시험(KAT)으로 구분되며, 다음과 같은 순서로 진행된다."

1.  **동작 전 핵심기능시험(KAT)**: 탑재된 검증대상 암호 알고리즘(SEED, SHA-256, HMAC, RSAES, RSA-PSS, DH 등)에 대해 사전에 CAVP 등을 통해 검증된 테스트 벡터를 사용하여 연산 결과의 정합성을 검증함.
2.  **동작 전 소프트웨어 무결성 시험**: 암호모듈 바이너리에 대한 무결성 검증값을 계산하고, 사전에 연접되어 있는 참조값과 비교하여 변조 여부를 확인함.

### 3.2. 서비스 제공 조건
- 모든 동작 전 자가시험이 성공적으로 완료된 경우에만 암호모듈은 '정상 동작 상태'로 운영자에게 암호 서비스를 제공할 수 있다.
- 자가시험이 완료되기 전까지는 어떠한 암호 연산이나 데이터 출력도 허용되지 않는다.

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 모듈 초기화 시퀀스 및 시험 순서 제어에 집중함.
> **논리 흐름**: [모듈 로드] → [초기화 진입] → [핵심기능시험(KAT) 수행] → [SW 무결성 시험 수행] → [모든 시험 통과] → [정상 서비스 모드 진입]

## 5. 해설 및 증빙 가이드 (Guide)
- **AS10.07과의 연계**: 본 항목은 동작 전 자가시험과 조건부 자가시험에 대해 상세히 명세하는 AS10.07 항목과 통합하여 기술해야 함.
- **수행 항목의 전수 조사**: 모듈에 탑재된 모든 검증대상 알고리즘이 동작 전 자가시험 목록에 포함되어 있는지 확인이 필요함.
- **순서의 명확성**: 핵심기능시험과 무결성 시험 중 어떤 것이 선행되는지, 그리고 전체 시험이 성공해야만 서비스가 개시됨을 설계서에 명확히 기술해야 함.
