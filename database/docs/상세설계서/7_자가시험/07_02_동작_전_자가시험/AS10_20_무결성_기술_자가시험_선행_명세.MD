# [AS10.20] 소프트웨어/펌웨어 시험 전, 무결성 기술에 대한 자가시험 수행

## 1. 보안요구사항 개요
암호모듈의 무결성을 검증하기 위해 사용되는 무결성 기술(알고리즘)에 대하여, 무결성 시험을 수행하기 전 해당 알고리즘이 정상적으로 동작하는지 확인하기 위한 자가시험을 선행해야 함을 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.20.01**: 소프트웨어/펌웨어 시험에 사용된 검증대상 무결성 기술에 대해 자가시험 선행에 대한 명세

## 3. 작성 예시 (Examples)

### 3.1. 무결성 기술 자가시험 선행 프로세스
"본 암호모듈은 동작 전 소프트웨어 무결성 시험을 수행하기 전, 무결성 검증에 사용되는 알고리즘(예: HMAC-SHA256)에 대하여 핵심기능시험(KAT)을 우선적으로 수행한다."

- **수행 시나리오 1**: 
    1. 무결성 기술을 포함한 모든 암호 알고리즘에 대한 KAT 시험 수행
    2. 동작 전 소프트웨어 무결성 시험 수행
- **수행 시나리오 2**:
    1. 무결성 기술(예: RSA-PSS)에 대한 KAT 시험 수행
    2. 동작 전 소프트웨어 무결성 시험 수행
    3. 나머지 알고리즘들에 대한 핵심기능시험(KAT) 수행

### 3.2. 자가시험 구성의 정합성
"동작 전 자가시험의 구체적인 순서와 목록은 상세설계서의 [동작 전 자가시험 목록] 표에 정의되어 있으며, 무결성 기술에 대한 자가시험이 무결성 검증 단계보다 선행되도록 제어 흐름을 설계하였다."

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 자가시험의 선후 관계 및 논리적 인과성에 집중함.
> **논리 흐름**: [무결성 알고리즘 KAT] → [정상 동작 확인] → [소프트웨어 무결성 시험] → [통과 시 정상 서비스 모드 진입]


## 5. 해설 및 증빙 가이드 (Guide)
- **KAT 시험 간소화**: 상위 수준 알고리즘(예: RSA-PSS)에 대한 KAT를 수행할 때 내부 알고리즘(예: SHA-256)에 대한 연산이 함께 검증된다면, 내부 알고리즘에 대해 별도의 KAT를 중복 수행할 필요는 없음. (단, KAT가 수행되지 않은 별개의 기능이 있다면 반드시 해당 기능에 대한 시험을 포함해야 함)
- **선행 조건의 필수성**: 무결성 기술 자체가 고장 난 상태에서 무결성 시험을 수행하는 것은 보안적으로 의미가 없으므로, 반드시 알고리즘의 정상 동작 여부를 먼저 확인하는 로직이 소스코드에 반영되어야 함.
- **표준 준수**: KAT 시험의 간소화 방법 및 세부 사항은 '암호모듈 구현안내서(GVI Part I)'의 기준을 준수하여 작성할 것.
