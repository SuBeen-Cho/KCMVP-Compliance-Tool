# [AS10.17] 동작 전 소프트웨어/펌웨어 무결성 시험 명세

## 1. 보안요구사항 개요
암호모듈이 동작하기 전, 모듈을 구성하는 모든 소프트웨어 및 펌웨어 구성요소의 무결성을 검증하기 위한 기술적 방법과 상세 절차를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.17.01~04**: 소프트웨어/펌웨어 무결성 시험에 대한 상세 명세

## 3. 작성 예시 (Examples)

### 3.1. 무결성 검증 기술 및 프로세스
"본 암호모듈은 소프트웨어 라이브러리 형태로서, 자체적인 무결성 검증 기술을 사용하여 모든 구성요소에 대한 무결성 시험을 수행한다. 무결성 검증값 생성 및 최종 모듈 생성 과정은 다음과 같은 메커니즘 중 하나를 선택하여 적용한다."

- **HMAC 기반 무결성 검증**: 검증대상 암호알고리즘인 HMAC-SHA256을 사용하여 모듈 바이너리에 대한 무결성 검증값을 생성하고, 초기화 시점에 실시간 계산값과 기저장된 참조값을 비교함.
- **RSA-PSS 기반 무결성 검증**: 디지털 서명 표준인 RSA-PSS를 이용하여 모듈의 무결성을 검증하며, 공개키를 통해 서명의 정합성을 확인함으로써 변조 여부를 판단함.

### 3.2. 자가시험 수행 절차
1. **검증값 로드**: 모듈 초기화 API 호출 시, 사전에 연접되거나 별도 저장된 무결성 참조값을 로드함.
2. **실시간 계산**: 현재 로드된 소프트웨어 구성요소(바이너리 영역 등)에 대해 선택된 알고리즘(HMAC 또는 RSA-PSS)으로 무결성 검증값을 동적으로 계산함.
3. **비교 및 결정**: 참조값과 실시간 계산값이 일치하는지 확인하며, 불일치 시 즉시 오류 상태로 전이하여 서비스를 차단함.

## 5. 해설 및 증빙 가이드 (Guide)
- **섹션 간 정합성**: 본 항목은 상세설계서의 **'05. 소프트웨어/펌웨어 보안'** 장(AS05.05, AS05.06)에서 다루는 무결성 보호 내용과 논리적으로 일치해야 하며, 상호 참조를 통해 상세 내용을 보완할 수 있음.
- **검증 알고리즘의 승인 여부**: 무결성 시험에 사용되는 알고리즘(HMAC, RSA-PSS 등)은 반드시 검증대상 암호알고리즘 목록에 포함되어 있어야 하며, 해당 알고리즘의 KAT 결과가 신뢰할 수 있음을 전제로 함.
- **수도코드 제공**: 무결성 시험을 수행하는 구체적인 로직을 수도코드(Pseudocode) 형태로 제시하여, 검증값이 어떻게 계산되고 비교되는지 소스코드 레벨의 증빙을 포함해야 함.
