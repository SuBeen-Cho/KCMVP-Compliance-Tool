# [AS10.24] 동작 전 핵심기능시험 명세

## 1. 보안요구사항 개요
암호모듈 초기화 시, 탑재된 모든 검증대상 암호알고리즘에 대하여 KAT(Known Answer Test) 방식의 자가시험을 수행함으로써 알고리즘 구현의 정확성을 검증해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.24.01**: 동작 전 핵심기능시험에 대한 명세 (시험 항목, 방법, 참조표준 등)

## 3. 작성 예시 (Examples)

### 3.1. [표] KISACrypto V1.0 암호알고리즘 시험 상세 명세
| 알고리즘 | 수행방법 (KAT) | 참조표준 및 출처 |
| :--- | :--- | :--- |
| **SEED-128** | CBC, CTR 운영모드에 대해 키, 평문, 암호문에 대한 KAT 수행 | KS X 3254, KS X 3276 |
| **SHA-256** | 56/62바이트 메시지에 대한 해시값 KAT 수행 | ISO/IEC 10118-3 |
| **HMAC** | HMAC-SHA-256에 대해 암호키와 메시지 기반 KAT 수행 | TTAK.KO-12.0330-Part2 |
| **HMAC_DRBG** | 엔트로피, 논스, 개별화 문자열 등 시나리오별 난수 출력 KAT 수행 | TTAK.KO-12.0332-Part2 |
| **RSAES** | 3072-bit 키쌍, 메시지, 랜덤 시드 기반 암/복호화 KAT 수행 | 사전검증서비스(CAVP) |
| **RSA-PSS** | 3072-bit 키쌍, 메시지, 랜덤 솔트 기반 서명 및 검증 KAT 수행 | 사전검증서비스(CAVP) |
| **DH** | 2048/3072-bit 파라미터 및 키쌍 기반 키합의 KAT 수행 | 사전검증서비스(CAVP) |

### 3.2. 핵심기능시험 수도코드 (SEED 알고리즘 예시)
"테스트 벡터는 소스코드에 하드코딩되어 있으며, 시험 종료 후 사용된 임시 변수는 즉시 제로화한다."

```c
// SEED KAT 수행 함수 구조
int seed_kat_test() {
    // 1. 테스트 벡터 로드 (SEED_TV 구조체 활용)
    for (int i = 0; i < sizeof(seedTestVectors); i++) {
        // 2. 암호화 KAT: 계산된 CT와 기저장된 CT 비교
        seed_encrypt(SEED_ENCRYPT, ..., &CT);
        if (memcmp(seedTestVectors[i].CT, CT, 16) != 0) return FAIL;

        // 3. 복호화 KAT: 계산된 PT와 기저장된 PT 비교
        seed_encrypt(SEED_DECRYPT, ..., &recovered);
        if (memcmp(seedTestVectors[i].PT, recovered, 16) != 0) return FAIL;
    }

    // 4. 사용된 내부 변수 제로화 (보안성 확보)
    memset(rk, 0, sizeof(rk));
    memset(CT, 0, sizeof(CT));

    return SUCCESS;
}
```

> **알림**: 본 항목은 알고리즘별 입력(TV)과 결과값의 비교 로직에 집중함.

## 5. 해설 및 증빙 가이드 (Guide)
- **KAT의 포괄성**: 동작 전 핵심기능시험에서 알고리즘 시험을 일괄적으로 수행할 경우, 특정 조건에서만 수행되는 조건부 자가시험을 생략할 수 있음.
- **테스트 벡터 출처**: 시험에 사용된 테스트 벡터가 KISA 사전검증 서비스(CAVP)나 표준 문서에서 제공하는 공신력 있는 데이터임을 설계서에 명시해야 함.
- **제로화 필수**: 자가시험 과정에서도 CSP(라운드 키 등)가 노출될 수 있으므로, 예시 코드와 같이 시험 종료 직후 메모리를 제로화하는 로직을 반드시 포함하고 증빙할 것.
