# [AS10.25] 조건부 자가시험 명세

## 1. 보안요구사항 개요
공개키 기반 키쌍 생성, 난수발생기 엔트로피 수집 등 특정 보안 이벤트가 발생할 때 수행되는 조건부 자가시험(Conditional Self-test)의 항목, 수행 방법 및 관련 소스코드 정보를 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.25.01**: 조건부 자가시험에 대한 명세

## 3. 작성 예시 (Examples)

### 3.1. [표] 조건부 키쌍 일치 시험 상세 명세
"공개키 알고리즘을 통해 새로운 키쌍을 생성할 때마다 해당 키쌍의 수학적 유효성을 즉시 검증한다."

| 항목 | 수행방법 | 관련 소스파일/함수 |
| :--- | :--- | :--- |
| **RSAES / RSA-PSS** | 생성된 키쌍에 대해 고정된 평문을 공개키로 암호화(서명) 후 개인키로 복호화(검증)하여 원본 평문과 일치하는지 확인 | `kisa_public_selftest.c`<br>(`rsaes_pairwise_test()`) |
| **DH 키 설정** | 생성된 파라미터와 키쌍을 매개변수로 하여 추가적인 임시 키쌍을 하나 더 생성 후, 키 합의 과정을 통해 도출된 공유키가 유효한지 검증 | `kisa_public_selftest.c`<br>(`dh_pairwise_test()`) |

### 3.2. [표] 조건부 알고리즘 시험 (엔트로피 건전성 시험)
"난수발생기(DRBG) 초기화 및 리시드 과정에서 수집되는 잡음원의 유효성을 실시간으로 검증한다."

| 항목 | 수행방법 | 참조표준 |
| :--- | :--- | :--- |
| **Instantiate 과정** | `get_entropy()` 함수 내에서 수집되는 잡음원에 대해 반복횟수 테스트(RCT) 및 적응성 비율 테스트(APT) 수행 | TTAK.KO-12.0306-R1 |
| **Reseed 과정** | 추가 잡음원 수집 시점에 실시간 건전성 함수를 호출하여 수집된 데이터의 엔트로피 밀도 확인 | TTAK.KO-12.0306-R1 |

## 5. 해설 및 증빙 가이드 (Guide)
- **Pair-wise Consistency**: 공개키 알고리즘의 경우 키쌍 생성 직후 반드시 이 시험을 거쳐야 하며, 시험에 사용된 임시 평문 및 결과값은 종료 후 즉시 제로화되어야 함.
- **엔트로피 건전성 시험의 수학적 근거**: TTAK.KO-12.0306-R1 표준에 의거하여 컷오프 값($C$)을 설정함.
    - 컷오프 값 $C$ 계산식: $C = \lceil 1 + \frac{-\log_2 \alpha}{\hat{H}} \rceil$
    - (예: 추정 엔트로피 $\hat{H}=8$, 유의수준 $\alpha=2^{-40}$인 경우 $C=6$)
    - **핵심 원리**: 추정 엔트로피 값이 높을수록 엄격한 기준(작은 $C$ 값)을 적용하여 잡음원의 품질을 보장함.
- **PQC 알고리즘 확장**: 수빈님이 연구 중인 **HAETAE(양자내성 전자서명)** 알고리즘 역시 키쌍 생성 시 Pair-wise Consistency Test를 수행하도록 설계하고, 이 항목의 목록에 추가하여 증빙할 것.
