# [AS10.34] 오류 탐지 시험 명세

## 1. 보안요구사항 개요
암호 알고리즘에 대한 기지 답안 시험(KAT)이나 비교 시험을 보완하기 위하여, 암호모듈 내부의 잡음원이나 연산 과정에서 발생할 수 있는 오류를 실시간으로 탐지하는 시험 구현 여부를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.34.01**: 오류 탐지 시험 구현 여부 및 상세 방법(절차, 결과) 명세

## 3. 작성 예시 (Examples)

### 3.1. 난수발생기(DRBG) 오류 탐지 시험 개요
"KISACrypto V1.0 암호모듈은 난수발생기 내의 엔트로피 소스가 정확하게 처리되고 있는지를 확인하기 위해 다음과 같은 두 가지 통계적 오류 탐지 시험을 수행한다. 시험 실패 시 해당 잡음원의 사용을 즉시 중단하고 심각한 오류 상태로 전이한다."

### 3.2. 반복 횟수 테스트 (Repetition Count Test, RCT)
"잡음원이 연속해서 동일한 값을 출력하여 보안 강도가 급격히 하락하는 상황을 탐지한다."

| 구분 | 내용 |
| :--- | :--- |
| **목적** | 잡음원의 'Stuck' 현상(동일 값 연속 출력) 감지 |
| **방법** | 연속적으로 동일한 값이 수집되는 횟수 $B$를 관찰하여 컷오프 $C$ 도달 여부 확인 |
| **컷오프 $C$** | $C = \lceil 1 + \frac{-\log_2 \alpha}{H} \rceil$ (단, $\alpha = 2^{-20}$, $H$ = 잡음원 엔트로피) |

### 3.3. 적응성 비율 테스트 (Adaptive Proportion Test, APT)
"환경 변화(온도, 전압 등)로 인해 잡음원의 엔트로피 밀도가 설계 당시의 평가치 미만으로 떨어지는지 감지한다."

| 구분 | 내용 |
| :--- | :--- |
| **목적** | 잡음원의 엔트로피 공급 능력 저하 탐지 |
| **방법** | 특정 범위(윈도우 사이즈 $W$) 내에서 첫 번째 잡음원 값과 동일한 값의 발생 횟수 $B$를 관찰 |
| **컷오프 $C$** | $C = 1 + \text{CRITBINOM}(W, 2^{-H}, 1 - \alpha)$ |

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 잡음원의 실시간 통계 분석 및 임계치 제어 로직에 집중함.
> **논리 흐름**: [잡음원 수집] → [RCT/APT 엔진 통과] → [카운트 $B$와 컷오프 $C$ 비교] → [정상: 시드 생성 사용 / 오류: 즉시 차단 및 오류 표시기 출력]


## 5. 해설 및 증빙 가이드 (Guide)
- **보완적 성격**: 오류 탐지 시험은 알고리즘의 논리적 정확성을 보는 KAT와 달리, 하드웨어나 외부 환경에 의존적인 잡음원의 '건전성'을 실시간으로 감시하는 보완적 장치임.
- **오류 조건 및 표시**: 
    - **조건**: 관찰값 $B$가 계산된 컷오프 $C$를 초과하는 경우를 오류 조건으로 설정함.
    - **표시**: 오류 탐지 시 AS10.08에서 정의한 고유 에러 코드(예: `KISA_ERR_ENTROPY_FAILURE`)를 반환함.
- **근거 제시**: 각 오류 조건이 실제 소스코드 상에서 어떻게 시험되는지(예: 카운터 변수의 증가 및 비교 로직) 소스파일명과 함수명을 포함하여 설명해야 함.
- **PQC 알고리즘과의 연관**: 수빈님이 연구 중인 **SMAUG-T**나 **HAETAE**와 같은 알고리즘은 샘플링 과정에서 고품질의 난수를 필요로 하므로, 이 조항에서 정의된 RCT/APT가 해당 알고리즘의 안전성을 뒷받침하는 핵심 근거가 됨.
