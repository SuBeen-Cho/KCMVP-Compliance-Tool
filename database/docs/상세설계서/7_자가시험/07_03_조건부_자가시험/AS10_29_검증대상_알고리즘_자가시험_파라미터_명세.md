# [AS10.29] 검증대상 알고리즘의 자가시험 대상의 파라미터 크기 명세

## 1. 보안요구사항 개요
암호모듈에 탑재된 검증대상 암호알고리즘의 자가시험 수행 시, 지원하는 모든 키 길이, 모듈 크기, 타원 곡선 등 파라미터 중 가장 작은 파라미터에 대한 시험을 포함해야 하며, 지원하는 운영모드 중 최소 한 개 이상에 대해 자가시험을 수행함을 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.29.01**: 키 길이, 모듈 크기, 타원 곡선 등은 가장 작은 파라미터 자가시험 수행, 운영모드 중 최소한 한 개 이상 자가시험 수행 여부 명세

## 3. 작성 예시 (Examples)

### 3.1. 자가시험 대상 파라미터 및 운영모드 설정
"KISACrypto V1.0 암호모듈은 모든 검증대상 알고리즘에 대하여 동작 전 핵심기능시험(KAT)을 통해 자가시험을 수행한다. 특히 파라미터 크기와 운영모드에 대해 다음과 같은 원칙을 적용하여 시험을 설계하였다."

- **파라미터 크기**: 지원하는 키 길이(예: 128, 192, 256-bit) 및 모듈 크기 중 보안 강도가 가장 낮은 '가장 작은 파라미터'를 포함하여 자가시험을 수행함.
- **운영모드**: 알고리즘별로 지원하는 운영모드(CBC, CTR, GCM 등) 전체에 대해 자가시험을 수행하여 구현의 정확성을 전수 검증함.

## 4. 구조도 및 시각 자료 (Visuals)
> **설계 핵심**: 본 항목은 자가시험의 '범위(Coverage)'와 '대표성(Smallest Parameter)'에 집중함.
> **논리 흐름**: [알고리즘별 지원 파라미터 식별] → [최소 파라미터 선정] → [운영모드별 KAT 구성] → [자가시험 목록 반영] → [동작 전 시험 수행]

## 5. 해설 및 증빙 가이드 (Guide)
- **KAT 간소화 시험 (KAT Simplification)**: KCMVP 제도에서는 기본적으로 모든 옵션에 대해 자가시험을 요구하지만, 상위 수준 알고리즘(예: 서명 알고리즘)에 대한 KAT를 수행할 때 내부 알고리즘(예: 해시 함수)이 함께 동작한다면, 내부 알고리즘에 대한 별도의 KAT는 간소화(생략)할 수 있음.
- **중복 시험 방지**: 다른 KAT를 통해 이미 기능적 정확성이 한 번 확인된 구현물의 경우에는 추가적인 KAT를 수행하지 않아도 무방함. 단, 간소화 논리를 설계서에 명확히 기술해야 함.
- **최소 파라미터의 의미**: 보안 요구사항에서 '가장 작은 파라미터'를 명시하는 이유는 최소한의 보안 환경에서도 알고리즘이 정상적으로 동작함을 보장하기 위함임.
