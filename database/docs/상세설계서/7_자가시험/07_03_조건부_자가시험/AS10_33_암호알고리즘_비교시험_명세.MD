# [AS10.33] 암호알고리즘 비교시험 명세

## 1. 보안요구사항 개요
암호 알고리즘의 구현 정확성을 검증하기 위하여, 알고리즘을 두 번 이상 독립적으로 구현한 후 그 출력값을 비교하는 자가시험을 수행할 경우 해당 시험의 절차와 결과를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.33.01**: 구현된 암호알고리즘의 비교 자가시험 명세
- **VE10.33.02**: 비교 자가시험의 절차 및 결과 판정 기준 명세

## 3. 작성 예시 (Examples)

### 3.1. 비교시험 수행 정책
"KISACrypto V1.0 암호모듈은 특정 조건부 암호알고리즘 시험을 수행함에 있어, 알고리즘의 신뢰성을 극대화하기 위해 비교시험 방식을 적용할 수 있다. 상세한 수행 방법은 [암호알고리즘 시험 상세 명세]의 절차를 따르며, 비교시험이 사용되는 경우 해당 시험의 구체적인 단계와 결과를 명확히 기록한다."

### 3.2. 비교시험 절차 및 판정 기준
- **수행 절차**:
    1. 동일한 암호 알고리즘을 서로 다른 방식(예: 최적화 방식과 참조 구현 방식 등)으로 두 번 이상 독립적으로 구현함.
    2. 동일한 입력값(평문, 키 등)에 대하여 각 구현물의 출력값을 생성함.
    3. 생성된 두 개 이상의 출력값을 비트 단위로 비교함.
- **결과 판정**:
    - **성공**: 모든 구현물의 출력값이 완벽히 일치하는 경우.
    - **실패**: 출력값 중 하나라도 일치하지 않는 경우, 비교 자가시험 실패로 판정하고 즉시 오류 상태로 전이함.

## 4. 구조도 및 시각 자료 (Visuals)
> **설계 핵심**: 본 항목은 구현물 간의 독립성과 결과의 일관성 검증에 집중함.
> **논리 흐름**: [독립적 구현물 A, B 준비] → [동일 입력값 주입] → [출력값 추출] → [비교 연산] → [일치 확인] → [정상 동작 확정]

## 5. 해설 및 증빙 가이드 (Guide)
- **독립적 구현의 의미**: 비교시험의 신뢰성을 위해 각 구현물은 서로 다른 로직이나 라이브러리를 기반으로 작성되는 것이 권장됨.
- **AS10.27과의 연계**: 본 시험 항목은 암호알고리즘 최초 사용 전 조건부 자가시험(AS10.27)의 세부 이행 방법으로 포함되어 명세될 수 있음.
- **실패 시 처리**: 비교시험 실패는 알고리즘 구현 자체의 결함으로 간주되므로, AS10.07~10에서 정의한 심각한 오류 처리 절차(서비스 차단 및 재설치 요구)를 동일하게 적용해야 함.
