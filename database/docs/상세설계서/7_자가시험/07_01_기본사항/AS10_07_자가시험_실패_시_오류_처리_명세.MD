# [AS10.07] 자가시험 실패 시 오류 처리 명세

## 1. 보안요구사항 개요
암호모듈 초기화 시 수행되는 동작 전 자가시험 및 특정 조건 발생 시 수행되는 조건부 자가시험이 실패할 경우, 발생 조건, 오류 명칭(코드), 그리고 이를 해제하기 위한 복구 방법을 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.07.01**: 오류 발생 조건, 명칭, 해제 방법에 대한 명세

## 3. 작성 예시 (Examples)

### 3.1. 동작 전 자가시험(Pre-operational Self-test) 목록 및 오류 처리
"KISACrypto V1.0은 모듈 초기화 과정에서 소프트웨어 무결성 시험과 알고리즘 KAT(Known Answer Test)를 수행한다. 실패 시 모듈은 서비스를 차단하고 심각한 오류 상태로 전이된다."

| 세부 시험 항목 | 오류 발생 조건 | 오류 코드(명칭) | 해제 방법 |
| :--- | :--- | :--- | :--- |
| **SW 무결성 시험** | 바이너리 또는 무결성 검증값 변조 시 | `KISA_PreSelfTest_Integrity_Fail` | 모듈 재시작 또는 재설치 |
| **블록암호 (SEED)** | 암호화/복호화 KAT 결과 불일치 | `KISA_PreSelfTest_BlockCipher_SEED_Fail` | 모듈 재시작 또는 재설치 |
| **해시함수 (SHA-256)** | 해시 연산 결과값 불일치 | `KISA_PreSelfTest_Hash_SHA_Fail` | 모듈 재시작 또는 재설치 |
| **메시지인증 (HMAC)** | MAC 값 연산 결과 불일치 | `KISA_PreSelfTest_MAC_HMAC_Fail` | 모듈 재시작 또는 재설치 |
| **난수발생 (DRBG)** | 기정의된 시드 대비 출력값 불일치 | `KISA_PreSelfTest_DRBG_HMACDRBG_Fail` | 모듈 재시작 또는 재설치 |
| **공개키암호 (RSAES)** | OAEP 인코딩 또는 암/복호화 실패 | `KISA_PreSelfTest_Public_RSAES_Fail` | 모듈 재시작 또는 재설치 |
| **전자서명 (RSA-PSS)** | 서명 생성 또는 검증 결과 불일치 | `KISA_PreSelfTest_Digital_RSAPSS_Fail` | 모듈 재시작 또는 재설치 |
| **키 설정 (DH)** | 키 합의 연산 결과 불일치 | `KISA_PreSelfTest_KA_DH_Fail` | 모듈 재시작 또는 재설치 |

### 3.2. 조건부 및 주기적 자가시험 목록 및 오류 처리
"특정 이벤트(키쌍 생성, 엔트로피 수집 등) 발생 시 수행되는 시험이며, 실패 시 해당 서비스 사용이 제한된다."

| 세부 시험 항목 | 오류 발생 조건 | 오류 코드(명칭) | 해제 방법 |
| :--- | :--- | :--- | :--- |
| **키쌍 일치 시험** | 생성된 키쌍(RSA, DH)의 수학적 불일치 | `KISA_CondTest_[알고리즘]_PairKey_Fail` | 모듈 재시작 또는 재설치 |
| **잡음원 건전성 시험** | 엔트로피 수집 시 RCT 또는 APT 통과 실패 | `KISA_CondTest_DRBG_Health_Fail` | 모듈 재시작 또는 재설치 |
| **주기적 자가시험** | 동작 전 자가시험과 동일 요건 실패 | (동작 전 자가시험과 동일) | 모듈 재시작 또는 재설치 |

## 4. 구조도 및 시각 자료 (Visuals)
> **논리 흐름**: [모듈 초기화] → [무결성 시험] → [알고리즘 KAT] → [실패 시 즉각 서비스 차단 API 호출] → [심각한 오류 상태 유지] → [로그 기록/오류 코드 반환]

## 5. 해설 및 증빙 가이드 (Guide)
- **KAT 간소화 원칙**: 상위 알고리즘(예: RSA-PSS)의 KAT가 하위 알고리즘(예: SHA-256)의 기능을 포함하는 경우, 상위 알고리즘 시험 성공 시 하위 알고리즘 시험을 수행한 것으로 간주할 수 있음.
- **오류 상태의 지속성**: 자가시험 실패로 발생한 '심각한 오류 상태'는 단순히 API를 다시 호출한다고 해제되어서는 안 되며, 반드시 프로세스 재시작이나 재설치를 통해서만 복구되어야 함을 강조해야 함.
- **건전성 시험(Health Test)**: 난수발생기에서 새로운 잡음원을 수집할 때마다 반복 횟수 테스트(RCT)와 적응성 비율 테스트(APT)가 실시간으로 동작함을 설계서에 반영해야 함.
- **LEA 알고리즘 적용**: 수빈님이 연구 중인 LEA 알고리즘 역시 동작 전 자가시험 목록에 포함시켜야 하며, 실패 시 `KISA_PreSelfTest_BlockCipher_LEA_Fail`과 같은 독자적인 오류 코드를 할당할 것.
