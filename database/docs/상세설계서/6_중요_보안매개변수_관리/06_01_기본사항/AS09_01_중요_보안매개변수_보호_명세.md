# [AS09.01] 암호모듈 내의 CSP에 대한 보호

## 1. 보안요구사항 개요
암호모듈 내부에서 생성 및 사용되는 모든 중요보안매개변수(CSP)에 대하여 인가되지 않은 접근, 사용, 노출, 변경 및 대체로부터 안전하게 보호하기 위한 물리적·논리적 보호 방법을 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE09.01.01**: 암호모듈 내에서 인가되지 않은 접근, 사용, 노출, 변경 및 대체로부터 모든 CSP에 대한 보호방법 명세 필요

## 3. 작성 예시 (Examples)

### 3.1. CSP 관리 원칙 및 보호 기법
"KISACrypto V1.0은 소프트웨어 라이브러리 형태의 모듈로서, 핵심 보안매개변수(CSP)의 생성과 제로화 기능을 제공한다. 모듈은 다음과 같은 보안 원칙을 준수하여 CSP를 보호한다."

- **[인가되지 않은 접근/사용 방지]**: 동적 라이브러리(DLL/SO) 형태로 빌드되어 응용 프로그램에 링크되며, 운영체제(OS)의 프로세스별 독립된 가상 메모리 보호 기능을 통해 타 프로세스의 접근을 원천 차단함.
- **[노출 방지]**: 모든 CSP는 API 내부에서만 임시로 사용되며, 사용이 종료되면 `KISA_Crypto_Zeroize()` 등을 통해 메모리에서 즉시 삭제(제로화)한 후 메모리를 반환함.
- **[변경/대체 방지]**: 운영체제의 커널 레벨 프로세스 보안 기능을 통해 프로세스 간 메모리 영역 침범 및 데이터 변조를 방지함.

### 3.2. [표] 핵심 보안매개변수(CSP) 상세 목록
| 분류 | 암호알고리즘 | 핵심 보안매개변수(CSP) |
| :--- | :--- | :--- |
| **블록암호** | SEED | 비밀키, 라운드키 |
| **메시지 인증코드** | HMAC | HMAC 키 |
| **난수발생기** | HMAC_DRBG | 엔트로피, 시드, 내부 상태(V, Key), 출력 난수 |
| **공개키 암호** | RSAES | 개인키, 시드 |
| **전자서명** | RSA-PSS | 서명키, 솔트 |
| **키설정** | DH | 개인키, 공유키 |

## 4. 구조도 및 시각 자료 (Visuals)

## 5. 해설 및 증빙 가이드 (Guide)
- **알고리즘별 CSP 식별**: 모듈에서 제공하는 블록암호, MAC, DRBG 등 각 서비스별로 어떤 데이터가 CSP에 해당하는지 전수 조사하여 목록화해야 함. (AS09.04와 연계)
- **OS 의존성 명세**: 소프트웨어 라이브러리의 경우, 실질적인 메모리 보호 주체가 운영체제이므로 사용하는 OS(Windows, Linux 등)가 제공하는 구체적인 보호 기술을 근거로 제시할 것.
- **Persistent Storage 보호**: 만약 제품형 소프트웨어와 같이 CSP를 HDD/SSD에 저장하는 기능이 있다면, 저장 시 사용되는 검증대상 암호알고리즘 보호 기법을 추가로 명세해야 함.
- **제로화의 확실성**: API 종료 직전 모든 중간값과 임시 데이터가 제로화되어 잔류 정보가 남지 않음을 논리적으로 입증하는 것이 심사의 핵심임.
