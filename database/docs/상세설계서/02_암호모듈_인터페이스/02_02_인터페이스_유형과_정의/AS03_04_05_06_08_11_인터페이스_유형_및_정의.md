# [AS03.04/05/06/08/11] 인터페이스 유형과 정의

## 1. 보안요구사항 개요
암호모듈이 제공하는 모든 암호 서비스에 대하여 데이터 입력, 데이터 출력, 제어 입력, 상태 출력의 관점에서 논리적 인터페이스를 정의하고, 각 서비스의 입력 데이터 및 출력 결과물을 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE03.04.01**: 암호모듈이 제공하는 서비스에 대한 논리적 인터페이스 명세
- **VE03.05.01**: 데이터 입력 인터페이스를 통해 입력되는 모든 데이터 명세
- **VE03.06.01**: 데이터 출력 인터페이스를 통해 출력되는 모든 데이터 명세
- **VE03.08.01**: 제어 입력 인터페이스를 통해 입력되는 제어 데이터 명세

## 3. 작성 예시 (Examples)

### 3.1. [표] 암호모듈에서 제공하는 암호 서비스 목록
| 서비스 분류 | API 명칭 | 동작 내용 | 입력 (데이터/제어) | 출력 (데이터/상태) |
| :--- | :--- | :--- | :--- | :--- |
| **초기화** | KISA_Crypto_initialize() | 모듈 초기화 | - | 오류코드(성공/실패) |
| **상태확인** | KISA_Crypto_getState() | 현재 상태 확인 | - | 암호모듈 상태값 |
| **버전확인** | KISA_Crypto_getVersion() | 이름 및 버전 확인 | - | 암호모듈 버전값 |
| **자가시험** | KISA_Crypto_selftest() | 주기적 자가시험 | - | 오류코드(성공/실패) |
| **블록암호** | KISA_Crypto_encrypt...() | 블록암호 암/복호화 | 설정정보, 평문/암호문, 키, IV | 암호문/평문, 오류코드 |
| **해시함수** | KISA_Crypto_hash...() | 해시함수 수행 | 설정정보, 메시지 | 해시값, 오류코드 |
| **메시지인증** | KISA_Crypto_hmac...() | HMAC 연산 수행 | 설정정보, 메시지, MAC 키 | HMAC 값, 오류코드 |
| **난수발생기** | KISA_Crypto_drbg...() | 난수 생성 | 설정정보, 엔트로피 등 | 난수비트열, 오류코드 |
| **공개키암호** | KISA_Crypto_genKeyPair() 등 | 키쌍 생성/암복호화 | 키길이, 평문/암호문, 키 | 키쌍, 결과물, 오류코드 |
| **키 설정** | KISA_Crypto_DH_...() | 도메인 변수/키 설정 | 키길이, 도메인 파라미터 | 공유키, 오류코드 |

### 3.2. [상세] 개별 암호 서비스 인터페이스 명세 (예시: encryptUpdate)
| 구분 | 내용 |
| :--- | :--- |
| **함수** | `int KISA_Crypto_encryptUpdate(u8 *output, u32 *outputLength, KISA_Block_CTX *ctx, const u8 *input, const u32 inputLength);` |
| **설명** | 블록 암호모듈의 암호화를 수행하기 위한 중간 단계 수행 (평문 입력 → 암호문 출력) |
| **데이터 입력** | `KISA_Block_CTX *ctx` (컨텍스트), `const u8 *input` (평문), `const u32 inputLength` (길이) |
| **데이터 출력** | `u8 *output` (암호문), `u32 *outputLength` (암호문 길이) |
| **제어 입력** | API 호출 자체 |
| **상태 출력** | `CIPHER_Process_SUCCESS` (성공), `CIPHER_ERROR_INVALID_INPUT` (실패: 입력 오류) 등 |

## 5. 해설 및 증빙 가이드 (Guide)
- **통합 명세 권고**: AS03.04는 입력(05), 출력(06), 제어(08), 상태(11)와 긴밀히 연관되므로, 위 예시처럼 통합된 표 형태로 명세하여 가독성을 높일 것.
- **상세 명세 필수**: 모든 암호 서비스에 대해 3.2절과 같은 상세 인터페이스 명세(함수 원형, 인자 설명 등)를 제출해야 함.
- **오류 코드 분류**: 상태 출력(표시기) 정의 시, 단순 오류(입력값 오류 등)와 심각한 오류(자가시험 실패, 하드웨어 에러 등)를 명확히 구분하여 정의하는 것이 심사 통과에 유리함.
- **상태 출력 종합**: AS03.11에서 요구하는 상태 출력 정보는 모든 암호 서비스의 반환값을 종합하여 별도의 상태 코드 일람표로 제시하는 것을 권장함.
