# [AS03.11] 상태 출력 인터페이스 명세

## 1. 보안요구사항 개요
암호모듈의 현재 동작 상태와 서비스 수행 결과를 논리적/물리적 표시기를 통해 출력해야 함. 특히 오류 발생 시 이를 분류하여 명세하고, 심각한 오류 시의 대응 방안을 포함해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE03.11.01**: 논리적, 물리적 표시기를 포함하는 상태 출력 인터페이스 명세
- **VE03.11.02**: 해당된다면, 상태 출력을 수행하는 외부 장치 명세 필요

## 3. 작성 예시 (Examples)

### 3.1. [표] 암호모듈 상태 목록 (상태 변수)
| 상태 변수 | 설명 | 값 |
| :--- | :--- | :--- |
| **STATUS_LOAD** | 초기화 전 | 0x000000 |
| **STATUS_INITIALIZE** | 초기화 중 | 0x000001 |
| **STATUS_SELFTEST** | 자가시험 수행 중 | 0x000002 |
| **STATUS_APPROVED** | 검증대상 동작모드 상태 | 0x000003 |
| **STATUS_NON_APPROVED** | 비검증대상 동작모드 상태 | 0x000004 |
| **STATUS_ERROR** | 심각한 오류 상태 | 0x000005 |
| **STATUS_TERMINATE** | 종료 상태 | 0x000006 |

### 3.2. [표] 서비스별 상태 출력 코드 명세 (성공/실패)
| 서비스 | 오류 명칭 | 오류 코드 | 오류 설명 | 오류 구분 |
| :--- | :--- | :--- | :--- | :--- |
| **공통** | SUCCESS | 0x000000 | 서비스 수행 성공 | 성공 |
| **블록암호** | BLOCK_INVALID_KEY_LENGTH | 0x100001 | 키 길이 오류 | 단순 오류 | 
| | BLOCK_PADDING_ERROR | 0x100003 | 패딩 오류 | 단순 오류 |
| | BLOCK_SELFTEST_FAIL | 0x100005 | KAT 자가시험 실패 | **심각한 오류** |
| **공개키** | PUBLIC_INVALID_INPUT | 0x200004 | 잘못된 입력 오류 | 단순 오류 |
| | PUBLIC_SELFTEST_FAIL | 0x200005 | KAT 자가시험 실패 | **심각한 오류** |
| | PUBLIC_COND_SELFTEST_FAIL | 0x200006 | 조건부 자가시험 실패 | **심각한 오류** |

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [서비스 API 호출] → [내부 상태 확인] → [연산 수행 및 결과 판별] → [오류 구분(단순/심각)에 따른 코드 반환] → [심각한 오류 시 서비스 차단 및 상태 유지]

## 5. 해설 및 증빙 가이드 (Guide)
- **오류의 분류**: 사용자의 실수(잘못된 인자 입력 등)로 인한 '단순 오류'와 모듈의 안전성에 영향을 주는 '심각한 오류(자가시험 실패 등)'를 명확히 구분하여 명세해야 함.
- **심각한 오류 대응**: 심각한 오류 발생 시 모듈은 오류 상태를 유지하며 이후의 서비스 요청을 거부해야 함. 이를 해결하기 위한 리부팅 또는 재설치 절차를 운영 가이드에 포함할 것.
- **CSP 제로화**: 정상 동작 종료 후 또는 오류 발생 시 사용되었던 중요보안매개변수(CSP)를 제로화하는 메커니즘이 상태 출력과 연동되어 있는지 확인이 필요함.
- **통합 명세**: AS03.04에서 정의한 인터페이스를 기반으로 하되, 본 항목에서는 서비스별 상태 출력을 종합하여 하나의 일람표로 제시하는 것을 권고함.
