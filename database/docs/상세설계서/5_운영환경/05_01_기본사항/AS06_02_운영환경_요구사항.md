# [AS06.02] 변경 가능한 운영환경의 운영체제 요구사항

## 1. 보안요구사항 개요
변경 가능한 운영환경(Modifiable Operational Environment)에서 보안수준 1 암호모듈을 운영하는 경우, 운영체제(OS)가 제공해야 하는 기본 보안 요구사항을 만족해야 함.

## 2. 상세 요구사항 (Requirements)
- **보안수준 1 요구사항**:
    1. 암호모듈의 각 인스턴스는 자신의 중요보안매개변수(SSP)를 제어해야 함.
    2. 운영환경은 응용 프로그램 프로세스를 독립적으로 유지하여 외부 프로세스로부터의 비인가된 접근 및 CSP 변경을 방지해야 함.
    3. 암호모듈로부터 생성된 프로세스는 해당 암호모듈에 의해서만 소유되어야 함.

## 3. 작성 예시 (Examples)
"본 암호모듈은 범용 운영체제(Windows, Linux 등)에서 제공하는 프로세스 격리(Isolation) 및 메모리 보호 기능을 활용한다. 각 모듈 인스턴스는 할당된 메모리 영역 내에서만 SSP를 관리하며, 운영체제의 접근 제어 정책에 따라 타 프로세스의 간섭을 차단한다. 관련한 세부 설정 및 보호 정책은 보안정책서(SP)의 운영환경 섹션에 상세히 기술한다."

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 운영체제의 보호 기능을 전제로 함.
> **논리 흐름**: [운영체제 커널] → [프로세스 독립성 보장] → [메모리 격리] → [암호모듈 CSP 보호]


## 5. 해설 및 증빙 가이드 (Guide)
- **단독 시험 불가**: 본 항목은 단독으로 심사되지 않으며, AS06.05~AS06.29 조항들과 연계되어 종합적으로 시험됨.
- **보안정책서 연동**: OS 수준에서 프로세스를 독립적으로 유지하기 위해 필요한 설정(예: 사용자 권한 분리, 메모리 보호 설정 등)이 있다면 이를 보안정책서 상에 명시해야 함.
- **소유권 증빙**: 암호모듈이 생성한 자식 프로세스나 스레드가 다른 모듈이나 응용 프로그램에 의해 탈취되지 않도록 관리되는 구조를 설명할 것.
