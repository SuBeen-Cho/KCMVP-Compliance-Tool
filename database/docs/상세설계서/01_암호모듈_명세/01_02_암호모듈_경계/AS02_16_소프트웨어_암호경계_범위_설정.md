# [AS02.16] 소프트웨어 암호모듈의 암호 경계에 대한 범위 설정

## 1. 보안요구사항 개요
소프트웨어 암호모듈이 실행되는 물리적 하드웨어 환경과 소프트웨어 환경(운영체제)을 정의하고, 모듈을 구성하는 모든 소스코드 파일 및 내부 구조를 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.16.01**: 구성요소를 명세한 개발문서 제출
- **VE02.16.02**: 구성요소가 상호 작동하는 방법을 포함한 내부 소프트웨어 구조를 명세한 개발문서 제출
- **VE02.16.03**: 암호모듈이 실행되는 소프트웨어 환경(운영체제, 실행 시간 라이브러리 등)을 명세한 개발문서 제출

### 3.1. [표] 암호모듈의 운영환경
| 구분 | 세부 항목 | 구성요소 |

| | **연산장치** | CPU |
| | **전원장치** | Power |
| | **입출력 장치** | Mouse, Keyboard, Monitor |

## 5. 해설 및 증빙 가이드 (Guide)
- **환경 명세의 구체성**: 단순히 'PC'라고 적는 것이 아니라 연산장치(CPU), 저장장치 등 하드웨어 구성 요소와 정확한 OS 버전(Ubuntu 24.04 등)을 명세해야 함.
- **소스코드 매핑**: 제출하는 모든 소스코드 파일(.c, .h)은 보안 요구사항(블록암호, 자가시험 등)과 일대일로 매칭되어 그 용도가 설명되어야 함.
- **상호작용 명세**: 각 소스파일이 `main` 모듈과 어떻게 상호작용하여 암호 서비스를 제공하는지에 대한 논리적 구조를 상세설계서에 포함할 것.
