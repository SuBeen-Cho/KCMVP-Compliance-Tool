# [AS02.14] 보안요구사항을 적용받지 않는 암호모듈의 구성요소 명세

## 1. 보안요구사항 개요
암호모듈 구성요소 중 보안요구사항을 적용받지 않는 요소가 있는 경우 이를 명확히 식별하고, 해당 요소가 오작동하거나 오용되더라도 암호모듈의 전체적인 보안성 및 검증대상 동작에 영향을 주지 않음을 증명해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.14.01**: 보안요구사항을 적용받지 않는 모든 구성요소를 명세한 개발 문서 제출
- **VE02.14.02**: 보안요구사항을 적용받지 않는 모든 구성요소 각각에 대해 근거 제출

## 3. 작성 예시 (Examples)

### 3.1. 서술형 예시
"KISACrypto V1.0은 보안 요구사항을 적용받지 않는 구성 요소가 존재하지 않는다."

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [전체 구성 요소 전수 조사] → [보안 요구사항 관련성 검토] → [미적용 요소 식별] → [상호 영향도 분석 및 독립성 검증] → [결과 명세]

## 5. 해설 및 증빙 가이드 (Guide)
- **근거 명세**: 보안 요구사항을 적용받지 않는 구성 요소가 존재한다면, 해당 요소가 오작동하거나 외부 공격에 의해 오용될 경우에도 암호모듈의 검증대상 동작모드를 손상시키지 않는다는 기술적 근거를 상세히 기술해야 함.
- **독립성 증명**: 미적용 요소와 보안 관련 요소 간의 논리적/물리적 격리 상태를 설명하여 보안 영향성이 없음을 강조할 것.
- **명시적 서술**: 작성 예시와 같이 미적용 요소가 없는 경우에는 "존재하지 않음"을 명확히 문서에 기재하여 심사 혼선을 방지함.
