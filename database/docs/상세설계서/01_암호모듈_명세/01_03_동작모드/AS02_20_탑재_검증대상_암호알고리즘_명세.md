# [AS02.20] 탑재된 검증대상 암호알고리즘 명세

## 1. 보안요구사항 개요
암호모듈에 탑재된 모든 검증대상 암호알고리즘의 목록과 각 알고리즘별 핵심보안매개변수(CSP), 구현적합성 검증 방법을 명세해야 함. 또한, 비검증대상 암호알고리즘이 포함된 경우 그 목록도 함께 제출해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.20.01**: 사전검토단계에서 구현적합성 검증을 수행할 검증대상 알고리즘 목록 제출
- **VE02.20.02**: 모든 비검증대상 암호알고리즘의 목록 제출

## 3. 작성 예시 (Examples)

### 3.1. [표] 탑재된 검증대상 암호알고리즘 및 구현적합성 검증 명세
| 구분 | 알고리즘 | 핵심 보안매개변수 | 검증대상 여부 | 구현적합성검증 |
| :--- | :--- | :--- | :---: | :--- |
| **블록암호** | SEED-128 | 비밀키, 라운드 키 | O | KAT, MMT, MCT |
| **해시함수** | SHA-256 | 해당사항 없음 | O | 짧은 메시지/긴 메시지/<br>임의메시지검증 |
| **메시지인증코드** | HMAC (SHA-256) | HMAC 키 | O | 임의메시지검증 |
| **난수발생기** | HMAC_DRBG (SHA-256) | 엔트로피, 내부상태(Key, V),<br>시드, 난수 | O | 임의메시지검증 |
| **공개키암호** | RSAES (3072, SHA-256) | 개인키, 시드 | O | 키쌍생성/암호화/<br>복호화검사 |
| **전자서명** | RSA-PSS (3072, SHA-256) | 서명키, 솔트 | O | 키쌍생성/서명생성/<br>서명검증검사 |
| **키설정** | DH (2048, 256), (3072, 256) | 개인키, 공유키 | O | 키쌍생성/공개키 유효성/<br>키설정기지 답안 검사 |

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [알고리즘 식별] → [핵심보안매개변수(CSP) 매칭] → [구현적합성 검증 시험 항목(KAT 등) 정의] → [검증대상/비검증대상 분류 목록화]

## 5. 해설 및 증빙 가이드 (Guide)
- **명확한 명칭 사용**: 탑재된 알고리즘은 알고리즘 명과 규격(키 길이, 해시 함수 등)을 명확히 기재해야 함.
- **구현적합성 검증 항목**: 각 알고리즘에 대해 수행할 구현적합성 검증 방법(KAT, MCT 등)을 실제 시험 계획과 일치하도록 명세해야 함.
- **비검증대상 알고리즘**: 만약 모듈 내에 비검증대상 알고리즘이 존재한다면, VE02.20.02에 따라 반드시 별도의 목록을 작성하여 제출해야 함 (없을 경우 "해당사항 없음" 명시).
- **연관 항목 참조**: 핵심보안매개변수 명세 시 AS02.22 보안요구사항을 참조하여 일관성을 유지할 것.
