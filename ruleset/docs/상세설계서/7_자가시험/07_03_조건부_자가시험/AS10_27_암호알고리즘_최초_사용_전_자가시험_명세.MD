# [AS10.27] 암호알고리즘 최초 사용 전 조건부 자가시험 명세

## 1. 보안요구사항 개요
암호 알고리즘이 실제 서비스에서 최초로 사용되기 이전에 해당 알고리즘의 무결성과 연산 정확성을 확인하기 위한 조건부 자가시험(KAT)을 수행하는 방법과 절차를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.27.01~03**: 암호알고리즘이 최초로 사용되기 이전에 조건부 자가시험을 수행하는 방법 명세

## 3. 작성 예시 (Examples)

### 3.1. 자가시험 수행 전략 및 방법
"KISACrypto V1.0은 암호 알고리즘의 신뢰성을 확보하기 위해 다음 두 가지 방식 중 **'방식 2'**를 채택하여 구현되었다."

- **방식 1: 호출 시점 시험 (On-demand Test)**
    - 알고리즘이 최초로 실행될 때 자가시험을 수행함.
    - **장점**: 필요한 알고리즘만 시험하여 초기 구동 속도가 빠름.
    - **단점**: 알고리즘별 시험 여부를 저장하는 상태 정보 관리가 복잡함.
- **방식 2: 초기화 시점 일괄 시험 (Pre-operational Batch Test)**
    - 암호모듈이 초기화(Power-up)되는 단계에서 탑재된 모든 검증대상 알고리즘에 대해 일괄적으로 KAT 시험을 수행함.
    - **장점**: 구조가 간편하고, 서비스 도중 자가시험으로 인한 지연이 없음.
    - **단점**: 초기화 시간이 다소 길어질 수 있음.

### 3.2. 알고리즘별 적용 명세
"상세한 수행 방법은 [KISACrypto V1.0 암호알고리즘 시험 상세 명세] 표의 기준을 따르며, 난수발생기(DRBG)의 경우 사용 시점에 엔트로피 건전성 시험을 별도로 수행한다."

## 5. 해설 및 증빙 가이드 (Guide)
- **전략의 선택**: 소프트웨어 라이브러리 형태라면 초기화 시점에 일괄 수행하는 '방식 2'가 KCMVP 심사 대응 및 구현 관점에서 훨씬 유리함. (AS10.24와 통합 증빙 가능)
- **상태 정보의 관리**: 만약 '방식 1'을 선택했다면, 각 알고리즘(LEA, RSA 등)의 시험 완료 플래그가 전역 변수로 어떻게 관리되는지 상세히 서술해야 함.
- **PQC 알고리즘 대응**: 수빈님이 연구 중인 **HAETAE**나 **SMAUG-T**와 같은 양자 내성 암호는 일반 암호보다 KAT 연산량이 많으므로, 초기화 시점에서 이들의 시험 시간이 전체 가용성에 미치는 영향을 고려하여 명세할 것.
- **정합성 유지**: 본 항목의 내용은 앞서 작성한 동작 전 핵심기능시험(AS10.24)의 목록 및 순서와 반드시 일치해야 함.
