# [AS10.28] KAT 형태의 조건부 암호알고리즘 시험 명세

## 1. 보안요구사항 개요
암호모듈에서 수행되는 모든 조건부 암호알고리즘 시험은 KAT(Known Answer Test) 형태로 수행되어야 하며, 각 알고리즘별로 적용된 KAT 시험 방법(입력값, 기대 결과값, 비교 로직 등)을 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE10.28.01**: KAT 형태의 조건부 암호알고리즘 시험 수행 여부 명세
- **VE10.28.02**: 알고리즘별 적용된 구체적인 KAT 시험 방법 명세

## 3. 작성 예시 (Examples)

### 3.1. 조건부 자가시험의 KAT 수행 정책
"KISACrypto V1.0 암호모듈은 모든 조건부 암호알고리즘 시험을 동작 전 핵심기능시험과 동일한 수준의 KAT 형태로 수행한다. 이는 알고리즘이 최초로 실행되거나 특정 조건(키 생성 등)이 발생했을 때 구현의 정확성을 즉각적으로 검증하기 위함이다."

### 3.2. 알고리즘별 KAT 시험 참조
"알고리즘별 세부적인 KAT 시험 항목, 방법, 참조 표준 및 테스트 벡터에 대한 상세 내용은 다음의 관련 항목 및 예시 코드를 참조한다."

- **상세 시험 항목 및 방법**: [AS10.24 동작 전 핵심기능시험 상세 명세] 표 참조
- **코드 구현 예시**: [SEED 알고리즘 KAT 시험 코드 예시] 참조 (테스트 벡터 비교 및 제로화 로직 포함)

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 알고리즘별 KAT 구현 방식의 다양성 및 정합성에 집중함.
> **논리 흐름**: [조건부 시험 트리거] → [해당 알고리즘 전용 KAT 함수 호출] → [기정의된 테스트 벡터 로드] → [연산 결과와 정답값 비교] → [일치 여부에 따른 상태 반환]

## 5. 해설 및 증빙 가이드 (Guide)
- **AS10.27과의 연관성**: 본 조항은 조건부 자가시험이 반드시 KAT 형태로 구현되어야 함을 강조함. 만약 '동작 전 일괄 시험' 전략을 선택했다면, 동작 전 수행되는 KAT가 곧 조건부 시험을 대체함을 논리적으로 기술해야 함.
- **알고리즘별 특수성**: 블록암호(LEA), 해시(SHA-256), 전자서명(RSA-PSS/HAETAE) 등 각 알고리즘마다 입력 데이터의 크기와 기대값이 다르므로, 시험 방법이 각 알고리즘의 표준 규격을 충족하는지 명시할 것.
- **증빙의 구체성**: 단순히 "KAT를 수행한다"는 기술보다는, AS10.24에서 정리한 상세 명세표와 소스코드 예시를 인용하여 실제 구현 여부를 명확히 증빙하는 것이 중요함.
