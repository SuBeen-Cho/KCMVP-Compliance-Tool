# [AS02.09] 경계 내의 알고리즘, 프로세스 등 보안관련 요소 명세

## 1. 보안요구사항 개요
암호경계 내에서 동작하는 모든 검증대상 암호알고리즘과 해당 알고리즘이 사용하는 핵심보안매개변수(CSP), 그리고 관련 보안 프로세스를 상세설계서에 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.09.01**: 경계안의 모든 구성요소들을 명세한 개발문서 제출

## 3. 작성 예시 (Examples)

### 3.1. [표] 암호알고리즘 및 핵심보안매개변수(CSP) 목록
| 구분 | 핵심보안매개변수(CSP) | 검증대상 암호알고리즘 상세 |
| :--- | :--- | :--- |
| **블록암호** | 비밀키, 라운드 키 | SEED (128비트, CBC/CTR 모드) <br> ※ 표준: KS X 3254, KS X 3276 |
| **해시함수** | 해당사항 없음 | SHA-256 <br> ※ 표준: KS X ISO/IEC 10188-3:2001 |
| **메시지 인증(HMAC)** | HMAC 키 | HMAC(SHA-256) <br> ※ 표준: KS X ISO/IEC 9797-2 |
| **공개키 암호** | 개인키 시드 | RSAES-OAEP (공개키 3072비트, Hash: SHA-256) <br> ※ 표준: KS X ISO/IEC 18033-2 |
| **난수 발생기** | 엔트로피, 내부상태, 시드, 난수 | HMAC_DRBG(SHA-256) <br> ※ 예측내성 미지원, 추가입력 미지원 |
| **전자서명** | 개인키 솔트 | RSA-PSS (공개키 3072비트, Hash: SHA-256) <br> ※ 표준: KS X ISO/IEC 14888-2 |
| **키 설정** | 개인키, 공유키 | DH 키 설정 (비대칭 기법 이용 메커니즘) <br> ※ 키 길이: (2048, 256), (3072, 256) |

## 5. 해설 및 증빙 가이드 (Guide)
- **표준 명시**: 암호알고리즘 명세 시 반드시 관련 KS 표준 번호를 함께 기재하여 검증 대상임을 명시해야 함.
- **CSP 매칭**: 각 알고리즘이 사용하는 핵심보안매개변수(비밀키, 솔트, 엔트로피 등)를 누락 없이 매칭하여 기술할 것.
- **최신성**: 관련 표준 규격은 국가사이버안보센터의 최신 가이드를 반드시 확인하여 작성함.
