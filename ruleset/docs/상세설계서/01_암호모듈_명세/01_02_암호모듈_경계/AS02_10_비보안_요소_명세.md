# [AS02.10] 비보안 요소 명세 및 근거 명세

## 1. 보안요구사항 개요
암호모듈 내에 포함된 비보안 요소(Non-security functions)를 명세하고, 해당 요소들이 검증대상 동작을 방해하거나 보안성에 영향을 주지 않음을 상세설계서에 명시해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.10.01**: 비보안 요소 명세

## 3. 작성 예시 (Examples)

### 3.1. 서술형 예시 (비보안 요소가 없는 경우)
"KISACrypto V1.0은 보안수준 1의 범용 소프트웨어 라이브러리형 암호모듈로서 검증대상 암호알고리즘에 대한 암호 서비스만을 제공하고 비보안 요소를 포함하지 않는다."

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [사용자 애플리케이션] → [암호 서비스 API 호출] → [검증대상 알고리즘 단독 실행] → [결과 반환 (비보안 기능 간섭 없음)]

## 5. 해설 및 증빙 가이드 (Guide)
- **명시적 기술**: 범용 소프트웨어 라이브러리형 암호모듈의 경우, 비보안 요소가 없다면 단순히 생략하는 것이 아니라 "비보안 요소를 포함하지 않음"을 명확하게 문서에 명세해야 함.
- **영향도 검토**: 만약 비보안 기능이 포함되어 있다면, 해당 기능이 암호 연산이나 핵심보안매개변수(CSP)에 접근하지 못함을 논리적으로 증명해야 심사를 통과할 수 있음.
