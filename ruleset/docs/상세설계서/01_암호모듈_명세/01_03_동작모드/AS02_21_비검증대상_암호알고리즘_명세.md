# [AS02.21] 비검증대상 암호알고리즘 및 서비스에 대한 명세

## 1. 보안요구사항 개요
검증대상 동작모드에서 사용되는 모든 비검증대상 암호알고리즘 및 서비스를 명세해야 하며, 해당 요소들이 검증대상 동작모드의 안전성에 영향을 미치지 않음을 논리적으로 증명해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE02.21.01**: 검증대상 동작모드에서 사용되고 있는 비검증대상 암호알고리즘에 대한 명세 필요
- **VE02.21.02**: 비검증대상 암호알고리즘이 검증대상 동작모드의 동작과 관련이 없다는 근거 제시

## 3. 작성 예시 (Examples)

### 3.1. 서술형 예시 (비검증대상 요소가 없는 경우)
"KISACrypto V1.0 암호모듈은 내부에 비검증대상 암호알고리즘을 포함하지 않으며 검증대상 암호알고리즘만을 이용하여 보안서비스를 응용 프로그램에게 제공한다."

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [모듈 내 전체 알고리즘 전수 조사] → [검증대상/비검증대상 서비스 분류] → [비검증대상 요소의 보안 영향도 분석] → [검증대상 동작모드와의 논리적 독립성 검증] → [최종 명세 작성]

## 5. 해설 및 증빙 가이드 (Guide)
- **사용 제한**: 비검증대상 알고리즘이나 프로세스뿐만 아니라, 명세되지 않은 기타 서비스도 검증대상 동작모드에서 운영자가 사용할 수 없도록 설계되어야 함.
- **예외적 사용 근거**: 비검증대상 알고리즘이 검증대상 프로세스의 일부분(예: 비보안 관련 보조 동작)으로 사용되는 경우에는 사용이 가능하나, 이 경우 해당 알고리즘이 전체 모듈의 안전성에 영향을 미치지 않는다는 명확한 기술적 근거를 제시해야 함.
- **독립성 증명**: 비검증대상 서비스가 암호 연산이나 핵심보안매개변수(CSP)에 접근할 수 없음을 상세설계서 상에서 입증할 것.
