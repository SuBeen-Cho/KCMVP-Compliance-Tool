# [AS09.02] 암호모듈 내의 PSP에 대한 보호

## 1. 보안요구사항 개요
암호모듈 내에서 생성 및 유지되는 모든 공개 보안매개변수(PSP)에 대하여 인가되지 않은 변경과 대체로부터 안전하게 보호하기 위한 논리적 보호 방법을 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE09.02.01**: 암호모듈 내에서 인가되지 않은 변경과 대체로부터 모든 PSP에 대한 보호방법 명세 필요

## 3. 작성 예시 (Examples)

### 3.1. PSP 보호 메커니즘 및 원칙
"KISACrypto V1.0 암호모듈 내에서 생성되는 공개 보안매개변수(PSP)는 CSP와 동일한 수준의 메모리 보호 정책을 적용받는다."

- **[변경 및 대체 방지]**: PSP가 암호모듈 인스턴스의 메모리 상에서 유지되는 동안, 운영체제(OS)가 제공하는 프로세스 메모리 보호 기능을 통해 타 프로세스에 의한 임의의 변경이나 대체를 차단함.
- **[메모리 제로화]**: 암호모듈 인스턴스가 할당된 메모리를 반환할 때, CSP와 마찬가지로 메모리에 저장되어 있던 PSP에 대해서도 `KISA_Crypto_Zeroize()` 등을 통한 제로화를 수행하여 잔류 정보를 삭제함.
- **[저장 시 보호]**: PSP를 HDD/SSD 등 영구 저장장치에 파일 형태로 저장할 경우, 이를 이용하는 응용 프로그램은 검증대상 암호알고리즘을 사용하여 저장된 PSP의 무결성을 보장하고 적절히 보호해야 함.

### 3.2. [표] 공개 보안매개변수(PSP) 상세 목록
| 분류 | 암호알고리즘 | 공개 보안매개변수(PSP) |
| :--- | :--- | :--- |
| **블록암호** | SEED | - CBC 운영모드(IV 값)<br>- CTR 운영모드(CTR 값) |
| **공개키 암호** | RSAES | - 공개키 |
| **전자서명** | RSA-PSS | - 검증키 |
| **키설정** | DH | - 공개키 |

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 운영체제의 메모리 통제 및 제로화 로직에 집중함.
> **논리 흐름**: [PSP 생성/사용] → [OS 프로세스 메모리 보호] → [외부 변경 시도 차단] → [서비스 종료] → [PSP 영역 제로화(Zeroization)] → [자원 반환]

## 5. 해설 및 증빙 가이드 (Guide)
- **CSP 보호 기법 준용**: 본 항목은 매개변수의 종류가 공개 데이터(PSP)로 바뀌었을 뿐, 논리적인 보호 방법은 AS09.01(CSP 보호)과 동일하게 적용되므로 일관성 있는 보호 로직을 제시해야 함.
- **무결성 강조**: PSP는 기밀성보다 '변경 및 대체'를 방지하는 무결성 보호가 핵심임. 특히 파일 저장 시 응용 프로그램 단에서 어떻게 무결성을 검증하는지 설계 근거를 명확히 할 것.
- **제로화의 범위**: 공개 데이터임에도 불구하고 보안 수준 유지를 위해 메모리 반환 시 제로화 절차가 반드시 포함되어야 함을 명세서에 기재할 것.
