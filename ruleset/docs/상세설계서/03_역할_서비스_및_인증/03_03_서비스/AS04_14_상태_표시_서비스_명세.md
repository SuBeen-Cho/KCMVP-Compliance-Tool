# [AS04.14] 상태표시 서비스 명세

## 1. 보안요구사항 개요
암호모듈의 현재 동작 상태와 각 서비스 수행 결과(성공/실패)를 명확히 출력하는 서비스를 정의해야 하며, 모듈이 가질 수 있는 모든 내부 상태를 상세히 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE04.14.01**: 암호모듈의 상태와 서비스 수행에 대한 결과를 출력하는 서비스 명세

## 3. 작성 예시 (Examples)

### 3.1. 상태 관리 변수 정의 (소스코드 레벨)
"KISACrypto V1.0은 암호모듈의 동작 중에 가질 수 있는 내부 상태를 다음과 같이 정의하여 관리한다."

```c
enum KCMVP_CRYPTO_MODULE_STATE
{
    KCMVP_CM_LOAD = KCMVP_CM_MODULE_STATE_BASE, // 암호모듈 로드(기본 상태)
    KCMVP_CM_PRE_SELFTEST,                      // 동작 전 자가시험 상태
    KCMVP_CM_NORMAL,                            // 정상동작 상태(검증대상 동작모드)
    KCMVP_CM_COND_SELFTEST,                     // 조건부 자가시험 상태
    KCMVP_CM_NORMAL_ERROR,                      // 단순 오류 상태
    KCMVP_CM_CRITICAL_ERROR,                    // 심각한 오류 상태
    KCMVP_CM_EXIT                               // 암호모듈 종료
};
```

### 3.2. 상태 표시 서비스 실행 결과 예시
"운영자는 `KISA_Crypto_getState()` API를 통해 모듈의 상태 변화를 확인할 수 있다."

**[성공 시: 초기화 및 정상동작 천이]**
```text
암호모듈 상태: 000003E8 (LOAD)
KCMVP_Initialize() 호출
KCMVP 암호모듈 초기화 결과: 1
암호모듈 상태: 000003EA (NORMAL)
```

**[실패 시: 자가시험 실패 및 심각한 오류 천이]**
```text
암호모듈 상태: 000003E8 (LOAD)
KCMVP_Initialize() 호출
KCMVP 암호모듈 초기화 결과: -1
암호모듈 상태: 000003ED (CRITICAL_ERROR)
```

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [상태 확인 요청] → [내부 상태 변수 참조] → [정의된 Enum 값 매핑] → [16진수 상태 코드 및 텍스트 결과 출력]

## 5. 해설 및 증빙 가이드 (Guide)
- **상태 코드의 일관성**: 소스코드에 정의된 `enum` 값과 실제 API가 반환하는 16진수 값(`0x000003E8` 등)이 일치하는지 전수 점검이 필요함.
- **서비스 결과 매핑**: 단순히 '성공/실패'만 보여주는 것이 아니라, 실패 시 어떤 오류 상태(단순/심각)로 천이되는지를 로그를 통해 증명해야 함.
- **시험서 연동**: 본 항목에서 명세한 상태 출력 서비스의 동작 결과는 향후 제출할 **'암호모듈 시험서'**의 결과와도 일치해야 하므로, 출력 포맷을 미리 확정해두는 것이 좋음.
