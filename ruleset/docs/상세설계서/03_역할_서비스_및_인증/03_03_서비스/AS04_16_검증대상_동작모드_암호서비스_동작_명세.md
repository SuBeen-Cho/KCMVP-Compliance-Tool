# [AS04.16] 검증대상 동작모드에서 제공하는 암호서비스에 대한 동작 명세

## 1. 보안요구사항 개요
검증대상 동작모드에서 제공되는 모든 암호 서비스(블록암호, 해시함수, 메시지인증코드, 난수발생기, 공개키 암호 등)에 대하여 실제 동작 시험 결과를 제시함으로써 설계된 대로 정확히 동작함을 명세해야 함.

## 2. 상세 요구사항 (Requirements)
*해당 항목은 별도의 VE 식별자 없이 동작 명세를 요구함.*

## 3. 작성 예시 (Examples)

### 3.1. 암호 서비스 동작 명세 개요
"KISACrypto V1.0은 블록암호, 해시함수, 메시지인증코드, 난수발생기, 공개키 암호에 대한 암호 서비스를 제공한다. 아래는 블록암호 알고리즘에 대한 동작 시험 수행 결과를 보이며, 각 알고리즘별 상세 시험 결과는 암호모듈 시험서에 별도로 명세되어 있다."

### 3.2. 블록암호 암복호화 시험 결과 예시
```text
[ARIA-128 ECB 모드 암복호화 시험]
평문 [16byte] : 
 80 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
암호문 [16byte] : 
 92 E5 1E 73 7D AB B6 BF D0 EA BC 8D 32 22 4F 77
복호문 [16byte] : 
 80 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```
*[블록암호 알고리즘에 대한 암복호화 시험 결과 출력 샘플]*

## 4. 구조도 및 시각 자료 (Visuals)
> **알림**: 본 항목은 별도의 아키텍처 다이어그램을 포함하지 않음. 
> **논리 흐름**: [암호 서비스 호출] → [검증대상 동작모드 확인] → [알고리즘 연산 수행] → [입출력 데이터 로깅] → [시험서 결과와 대조]

## 5. 해설 및 증빙 가이드 (Guide)
- **동작 결과의 구체성**: 단순히 "성공했다"는 서술에 그치지 않고, 작성 예시와 같이 실제 평문과 그에 대응하는 암호문 결과값을 제시하여 알고리즘의 구현 정확성을 입증해야 함.
- **시험서와의 연계**: AS04.16에서 요구하는 상세한 동작 시험 데이터는 실제 **'암호모듈 시험서'**의 데이터와 일관성을 유지해야 함. 상세설계서에는 대표적인 예시를 기술하고 전체 결과는 시험서를 참조하도록 구성하는 것이 바람직함.
- **전 서비스 망라**: 블록암호뿐만 아니라 모듈에서 지원하는 모든 검증대상 서비스(해시, MAC, DRBG 등)에 대해서도 동일한 형태의 동작 명세가 준비되어야 함.
- **검증대상 모드 한정**: 모든 동작 시험은 비검증대상 모드가 아닌, 반드시 '검증대상 동작모드(Approved Mode)' 상태에서 수행된 결과여야 함을 명시할 것.
