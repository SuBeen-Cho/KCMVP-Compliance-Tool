# [AS06.03] 암호모듈 구동을 위한 운영환경 정보 명세

## 1. 보안요구사항 개요
암호모듈을 동작시키기 위한 하드웨어 및 소프트웨어(운영체제) 환경 정보를 상세히 명세하고, 관리자 안내서 등에 해당 내용을 포함해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE06.03.01**: 암호모듈 동작 운영환경 정보, 설정, 관리자 안내서 명세

## 3. 작성 예시 (Examples)

### 3.1. [표] 지원 운영체제 및 하드웨어 명세
| 운영체제 (OS) | 버전 정보 | 비트 (Bit) | 비고 |
| :--- | :--- | :--- | :--- |
| **Windows 10 Pro** | Version 1607 (OS Build 14393.0) | 32/64-bit | x64 기반 프로세서 |
| **Ubuntu Linux** | 24.04.2 (Kernel 6.11.0) | 64-bit | SMP PREEMPT_DYNAMIC |

### 3.2. 운영환경 설정 절차
"암호모듈 사용을 위해서는 운영체제 내에 관리자 계정 생성 및 인증 절차가 사전에 완료되어야 한다. 각 운영체제가 제공하는 표준 사용자 관리 도구를 사용하여 계정을 생성하고, 암호모듈 라이브러리가 위치한 경로에 대한 접근 권한을 설정한다."

## 4. 구조도 및 시각 자료 (Visuals)

> **논리 흐름**: [운영환경 식별] → [OS/버전/비트 확인] → [인증 절차 마련] → [관리자 안내서 연동]


## 5. 해설 및 증빙 가이드 (Guide)
- **정보의 정확성**: 예시 스크린샷과 같이 `uname -a` (리눅스) 또는 시스템 정보 창(윈도우)을 통해 확인된 실제 데이터와 설계서의 내용이 일치해야 함.
- **전수 포함**: 암호모듈이 시험되는 모든 운영환경에 대한 정보(커널 버전, 서비스 팩 등)를 누락 없이 포함해야 함.
- **관리자 안내서(AG) 연동**: 본 조항에서 명세한 환경 설정 방법은 반드시 관리자 안내서에도 동일하게 기술되어야 함.
