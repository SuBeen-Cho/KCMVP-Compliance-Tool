# [AS11.29] 암호모듈 기능시험 (벤더 시험)

## 1. 보안요구사항 개요
개발업체(벤더)가 암호모듈이 제공하는 모든 보안 서비스에 대해 정상 동작 여부를 직접 확인하기 위해 수행한 기능 시험의 내용과 결과를 명세해야 함.

## 2. 상세 요구사항 (Requirements)
- **VE11.29.01**: 암호모듈에 대하여 수행된 기능시험 명세

## 3. 작성 예시 (Examples)
"암호모듈에 대한 벤더 시험은 별도의 추가 개발 문서인 **'암호모듈 시험서'**를 통해 증빙한다."

- **시험 목적**: 암호모듈이 제공하는 암호화, 복호화, 해시, 서명 등 모든 보안 서비스가 설계 규격에 맞게 정상적으로 동작하는지 개발 단계에서 전수 점검함.
- **시험 범위**: 기능 시험, 인터페이스 시험, 자가시험 동작 확인 등.

## 4. 해설 및 증빙 가이드 (Guide)
- **시험서의 구성**: 각 시험 항목별로 시험 목적, 시험 환경, 시험 절차, 기대 결과 및 실제 결과가 포함되어야 함.
- **설계 일치성**: 본 기능시험의 결과가 상세설계서에서 정의한 알고리즘 명세 및 서비스 동작과 일치함을 보여주어야 함.
- **KCMVP 대응**: 벤더 시험은 실제 검증 기관의 시험(V&V) 전 단계에서 모듈의 완성도를 입증하는 근거 자료로 활용됨.
