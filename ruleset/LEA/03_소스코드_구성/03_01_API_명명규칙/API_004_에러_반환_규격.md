# [API.004] 참조 배포 API 반환 계약

## 1. 적용 범위

본 문서는 `블록암호 LEA 소스코드 사용 매뉴얼(v1.0)` §4.3.12의 `lea_online_init` 반환 계약을 참조 프로파일로 기록한다. 원문은 해당 함수가 에러 발생 시 음수를, 정상 동작 시 0 이상의 정수를 반환한다고 설명한다.

## 2. 참조 계약

- **LEA-REF-RETURN-001**: 매뉴얼이 설명하는 `lea_online_init`의 반환값을 점검할 경우 성공은 0 이상, 에러는 음수인지 확인한다.

```c
int ret = lea_online_init(ctx, enc_type, mk, mk_len);
if (ret < 0) {
    /* 배포 API의 에러 처리를 수행한다. */
}
```

## 3. 비추론 한계

- 본 참조 계약을 모든 LEA API의 반환 규약으로 일반화하지 않는다.
- 독자 LEA 구현에 `return -N` 구문이 없다는 사실만으로 KCMVP 위반을 판정하지 않는다.
- 인증 암호화 실패 시 평문 제로화 등 다른 API의 세부 계약은 해당 원문 절을 별도로 고정하기 전에는 본 문서의 확정 근거로 사용하지 않는다.
- 활성 `LEA-044`는 비밀키 제로화 규칙이며 본 참조 프로파일과 연결하지 않는다.

## 4. 출처

- `블록암호 LEA 소스코드 사용 매뉴얼(v1.0)` §4.3.12 `lea_online_init`을 참조한다.
