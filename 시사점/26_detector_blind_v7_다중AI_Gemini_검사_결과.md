# Detector-blind v7 다중 AI·Gemini 검사 결과

## 목적과 주장 경계

본 실험은 정답을 암시하는 파일명·주석·식별자가 L1 후보 생성과 AI 라벨링에 미치는 영향을 차단한 후, 동일한 공개 패킷을 대상으로 다중 AI 판정을 수행한다. 본 결과는 내부 AI 블라인드 검사이며, 인간 암호모듈 전문가의 제3자 정답 라벨을 대체하지 않는다.

## Detector-side 누출 제거

사후 감사에서 기존 규칙 엔진이 `violations_` 파일명에 따라 회전 규칙의 정규화 동작을 달리하는 분기와, 해당 시험 파일을 분석하여 선정한 `_ROT_ALWAYS_NORMALIZE` 목록을 확인한다. 이는 벤치마크 정답 누출에 해당하므로 제거하고 파일명과 무관하게 동일한 정규화 정책을 적용한다.

주석을 공백·개행 보존 방식으로 제거한 193개 분석 소스에서 L1 후보 273건을 새로 생성한다. 동일 스냅샷을 재실행한 결과 273건이 동일하게 생성되었으며, 누락·추가 후보, 토큰 불일치, 전처리 불일치 및 컴파일 회귀는 각각 0건이다. 다만 원본과 정제본이 모두 컴파일되지 않아 동등성을 확정할 수 없는 소스 13개를 불확정으로 별도 기록한다.

불투명 경로·식별자 반사실험에서 결과가 달라지는 7개 규칙은 임의로 수정하지 않고 블라인드 정량평가에서 사전등록 제외한다.

- `CBC-LEA-005`
- `CTR-LEA-006`
- `COM-002`
- `COM-003`
- `LEA-022`
- `LEA-031`
- `LEA-043`

이 제외로 38개 후보가 정량 패킷에서 제외되어 최종 공개 패킷은 235건으로 구성된다. 표시 별칭의 의미 보존을 보장할 수 없는 58건은 코드를 공개하지 않고 문맥 불충분 후보로 제공한다.

## Gemini API 검사

`gemini-2.5-flash-lite`를 사용하여 235건을 후보별 독립 요청으로 판정한다. API 키는 `.env`에서만 로드하며 명령행, 원장, 결과 및 Git에 기록하지 않는다.

| 지표 | 결과 |
|---|---:|
| 성공 요청 | 235/235 |
| 재시도 | 0 |
| 위반 | 65 |
| 비위반 | 21 |
| 문맥 불충분 | 80 |
| 요구사항 비적용 | 69 |
| 입력 토큰 | 671,827 |
| 출력 토큰 | 55,690 |
| 평균 요청 시간 | 1,532.77 ms |
| 평균 자체 신뢰도 | 95.745 |

자체 신뢰도는 보정된 확률이 아니며 threshold calibration에 직접 사용하지 않는다. 또한 현재 스키마에서 `not_applicable`과 `insufficient_context`의 경계가 라벨러별로 다르게 해석되므로 후속 인간 라벨링 지침에 구체적 예시를 추가해야 한다.

## 다중 AI 검사

| 라벨 | 내부 AI A | 내부 AI B | Gemini API |
|---|---:|---:|---:|
| 위반 | 49 | 90 | 65 |
| 비위반 | 20 | 7 | 21 |
| 문맥 불충분 | 166 | 138 | 80 |
| 요구사항 비적용 | 0 | 0 | 69 |

| 비교 | 정확 일치율 | 다중분류 Cohen’s κ | 라벨 불일치 |
|---|---:|---:|---:|
| A–B | 79.57% | 0.5938 | 48 |
| A–Gemini | 51.91% | 0.3074 | 113 |
| B–Gemini | 49.36% | 0.2677 | 119 |

세 판정이 모두 일치한 후보는 112건으로, 문맥 불충분 70건, 위반 40건, 비위반 2건이다. 나머지 123건을 별도 AI 조정자가 재검토한 결과, 최종 내부 파일럿 분포는 위반 52건, 비위반 10건, 문맥 불충분 173건이다. 다중 AI 판정의 일치도가 낮은 부분은 해당 후보의 정답을 의미하지 않으며, 외부 전문가 조정이 필요한 대상을 식별한다.

## 결론과 다음 단계

detector-side 누출과 annotator-side 누출을 구분하여 검증하는 실험 경로를 구축하였다. 그러나 7개 규칙의 제외, 13개 소스의 컴파일 불확정, 58개 표시 문맥 보류 및 AI 판정 간 차이가 남아 있다. 따라서 본 결과로 precision·recall·F1을 산출하지 않는다. 다음 단계에서는 외부 전문가가 235건을 라벨링하고, 인간 조정이 완료된 occurrence 라벨만을 사용하여 성능 지표와 threshold calibration을 수행해야 한다.
