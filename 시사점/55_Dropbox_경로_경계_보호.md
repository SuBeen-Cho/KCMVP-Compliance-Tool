# Dropbox 경로 경계 보호

실험 산출물 경로는 한글 Dropbox 상위 경로를 문자열로 재구성하지 않고, 실행 모듈의 실제 경로와 `git rev-parse --show-toplevel`이 일치하는 저장소 루트에서만 생성한다. 공개 산출물은 Git 저장소 안에만 쓸 수 있고, 비공개 산출물은 명시적으로 허용한 `/private/tmp`에만 쓸 수 있다. 상위 Dropbox 또는 협업 폴더, 유사 문자 경로, 저장소 밖으로 향하는 심볼릭 링크는 출력 전에 차단한다.

현재 `current_router_universe_freeze` 출력에 이 경계 검증을 적용했다. 회귀 테스트는 정상 저장소 출력, 외부 임시 경로 차단, 명시적 비공개 경로, 심볼릭 링크 탈출 차단을 검증한다.
