# 9단계: MDPI 원고 수정

수정 대상은 데스크톱 최신 MDPI Overleaf 원고이다.

## 주요 변경

- 초록의 170+를 161 YAML assets로 정정하고 LEA/저자 구축 데이터 범위를 명시했다.
- L2를 입증된 정확도 개선이 아닌 evidence-provision mechanism으로 제한했다.
- 기여도에서 92 code + 65 document + 4 traceability 구성을 제시했다.
- dedicated checker 수를 25 LEA rule IDs / 24 implementations로 정정했다.
- 65~74를 heuristic setting으로 명시하고 calibration 필요성을 추가했다.
- 잘못 결합된 blind 34 files/14.5 KLOC/0.58 주장을 철회했다.
- case-study 표는 C-only와 C+H scope를 분리하고 candidate count를 canonical rerun 전까지 보류했다.
- author GT, L2 ablation, algorithm scope, threshold/cost를 limitation으로 추가했다.
- 결론의 L2 및 L3 효과 표현을 초기 LEA 데이터 범위로 낮췄다.

## 검증

- `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` 성공.
- 25페이지 PDF 생성, 치명적 LaTeX 오류 없음.
- MDPI class의 기존 `fancyhdr` headheight warning은 남아 있으며 본문 수정과 무관하다.
