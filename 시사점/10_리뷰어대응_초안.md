# 10단계: 리뷰어 대응 초안

## Reviewer 1 — 독립 검증

의견에 동의한다. 기존 128개 GT는 저자 구축 데이터이므로 초록·평가·한계에서 범위를 명시했다. 두 명의 외부 라벨러가 시스템 판정을 보지 않고 독립 판정하도록 blind package, Cohen's kappa 계산, disagreement adjudication 절차를 준비했다. 실제 인간 라벨링이 완료되기 전에는 이를 완료된 독립 검증으로 주장하지 않는다.

## Reviewer 1 — L2 독립 기여도

의견에 동의한다. 기존 before/after 기록은 GT와 결합되지 않아 L2 기여 증거로 불충분하다. `ABLATION_NO_RAG` 모드를 구현하여 prompt retrieval, context injection, report evidence를 함께 제거하고 단위 테스트로 검색 미호출을 확인했다. 동일 L1 후보에 대한 baseline/no-RAG paired run을 설계했다. 현재 저장된 API 키가 무효여서 새 수치를 보고하지 않으며, 원고에서는 L2를 evidence provision으로 제한했다.

## Reviewer 2 — AES·SEED 일반화

의견에 동의한다. 현재 제품 YAML은 LEA-centered이며 AES/SEED GT가 없다. 원고와 README의 범위를 축소했고, 세 알고리즘 모두 독립 GT가 없으면 일반화 주장을 거부하는 coverage gate를 추가했다. AES·SEED corpus와 per-algorithm confusion matrix가 확보되기 전에는 확장 성능을 주장하지 않는다.

## Reviewer 3 — 65~74 재평가 범위

해당 범위가 heuristic이었음을 원고에 명시했다. Brier score, ECE 및 인접 window sweep 분석 코드를 추가했으며, raw confidence가 포함된 canonical rerun 후 결과를 보고할 예정이다. 근거 없는 최적성 주장은 삭제했다.

## Reviewer 3 — 0.58 cases/KLOC

지적이 정확하다. 재감사 결과 C-only는 34 files/11,983 LOC, C+H는 59 files/14,511 LOC였다. 이전 원고는 두 scope를 혼합했다. 또한 legacy run의 candidate count도 7과 9로 일치하지 않아 0.58 주장을 철회하고 canonical rerun 전까지 frequency를 보고하지 않도록 수정했다.

## Reviewer 3 — 비용과 시간

단계별 monotonic timing, API calls, input/output tokens, pricing snapshot 기반 비용 계측을 추가했다. 기존 aggregate에는 telemetry가 있으나 immutable manifest가 없어 참고값으로만 분류했다. 유효한 API credential로 재실행한 값만 최종 표에 포함한다.

## 남은 외부 의존 사항

- 유효 Gemini API key
- AES/SEED 독립 GT corpus 및 라이선스 검토
- 실제 외부 인간 라벨러 2명 이상
- 저자 전체의 CRediT 역할 및 데이터 공개 범위 승인
