# 논문 수정추적본 완전성 검증

## 대상

- 검토본: `MDPI_논문_수정추적_영문_국문.md`
- 최신 원고: Desktop MDPI `overleaf`의 `main.tex`, `00abstract.tex`~`06conclusion.tex`, `references_generated.tex`
- 변경 기준: 직전 배포본 `KCMVP_MDPI_Overleaf_FAST.zip`

## 구조

검토본은 다음 세 층으로 구성한다.

1. 사람이 읽기 쉬운 영문·학술체 국문 검토층
2. 제3장의 최신 영문 원문·전체 국문 번역·변경 추적층
3. Markdown 변환에서 손실될 수 있는 인용·각주·상호참조를 보존하는 최신 LaTeX 원문층

그림 파일 삽입 명령은 제외하고 캡션을 유지한다. 참고문헌은 번역하지 않고 원문을 보존한다.

## 용어 원칙

- false positive: 오탐(FP)
- false negative: 미탐(FN)
- true positive: 참양성(TP)
- evidence: 증거
- guideline: 지침
- traceability: 추적성
- zeroization: 영구 삭제

한국어 서술은 학술체 `~한다`를 원칙으로 한다. 기존 번역층에 남은 동의어는 최종 교정 단계에서 위 표기로 통일한다.
