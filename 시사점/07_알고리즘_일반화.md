# 7단계: AES·SEED 일반화

- 현재 제품 YAML 알고리즘 규칙은 LEA 54개뿐이다.
- 외부 `CryptoModule.zip`에는 LEA/ARIA/AES가 있으나 독립 GT가 없으며, 기존 결과는 blind candidate frequency만 제공한다.
- SEED GT corpus는 작업공간에서 확인되지 않았다.
- `experiments.generalization.coverage_report`는 LEA/AES/SEED 각각에 GT 데이터가 없으면 일반화 주장을 자동으로 거부한다.
- 따라서 현 시점 논문은 LEA-centered prototype으로 제한하고 AES·SEED 성능 일반화를 주장하지 않는다.
- 후속 완료 조건: 공식/독립 구현의 라이선스 확인, mutation operator 사전 정의, 알고리즘별 독립 GT, per-algorithm confusion matrix와 macro average.
