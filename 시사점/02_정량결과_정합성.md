# 2~3단계: 정량 결과와 산정 방식 정합성

- `128 TP, 37 FP, 0 FN`은 산술상 precision 77.6%, recall 100%, F1 87.4%와 일치한다.
- 해당 결과 파일은 code/input/prompt manifest가 없어 `legacy_unverified`로 분류한다.
- blind ZIP 재계산 결과는 C 34개/11,983 physical LOC, C+H 59개/14,511 physical LOC이다.
- 논문의 `34 C files / 14.5 KLOC`는 파일 범위와 LOC 범위를 혼합했다.
- `7/14.5=0.48`, `7/12.0=0.58`, 최신 legacy 결과의 `9/12.0=0.75`이다.
- canonical 재실행 전에는 blind 수치를 핵심 성능 근거로 사용하지 않는다.

`experiments.canonical`은 legacy 산술을 검산하되 provenance 없는 결과의 승격을 차단한다.
