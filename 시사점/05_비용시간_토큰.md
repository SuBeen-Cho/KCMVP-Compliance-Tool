# 5단계: 비용·시간·토큰

- 기존 코드에 실제 API usage token counter가 존재한다.
- `experiments.telemetry.Telemetry`에 단계별 monotonic timing과 가격 snapshot 기반 비용 계산을 추가했다.
- 가격은 실행 시점의 모델·통화·출처·확인일과 함께 고정해야 하며 현재 웹 가격을 과거 실행에 소급 적용하지 않는다.
- legacy 종합 결과에는 317,536 input tokens, 40,909 output tokens, 138 calls, USD 0.048118, 1,934.9초가 기록되어 있으나 provenance 부족으로 참고치만 가능하다.
- 유효 API 키가 없어 현재 코드 기준 재측정은 완료되지 않았다.
