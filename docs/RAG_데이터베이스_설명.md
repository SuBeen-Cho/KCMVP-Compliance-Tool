# RAG용 데이터베이스가 뭔지, 지금 뭘 쓰고 있는지 (쉬운 설명)

---

## 1. RAG가 하는 일 (한 줄)

**위반이 하나 나올 때마다**  
→ “이 위반이 KCMVP 규정/가이드라인에서 **어디에 근거하는지**” 문장을 찾아서  
→ 위반 항목에 **근거(evidence)** 로 붙여 주는 것.

예: `COM-001` 위반 → “중요 보안매개변수 제로화는 KS X ISO/IEC 19790 §7.9에 따라…” 같은 문장을 찾아서 붙임.

---

## 2. “데이터베이스”가 뭐냐면

그 “근거 문장”을 **어디서 찾느냐**가 중요합니다.

- **근거 문장들이 들어 있는 문서들** = 이 프로젝트에서 말하는 **“RAG용 데이터”**
- 그걸 **어떤 방식으로 검색하느냐**에 따라 두 가지가 있습니다.

---

## 3. 방식 1: 마크다운 파일 + TF-IDF (지금 쓰는 것)

### 뭘 쓰나

- **데이터**: 프로젝트 안에 있는 **마크다운(.md) 파일들**
  - `database/docs/` (설계서·형상·시험 가이드라인)
  - `database/LEA/` (LEA 알고리즘/모드 가이드)
  - `backend/guidelines/` (기존 가이드)
- **검색 방식**: **TF-IDF**  
  = “검색어에 자주 나오는 단어”가 “그 문서에도 많이 나오면” 그 문서를 더 관련 있다고 보는 **단어 빈도 기반 검색**

### 비유

- **데이터** = 도서관 책장에 꽂힌 책(마크다운 파일들)
- **검색** = “제로화”, “COM-001” 같은 **단어**로 목차/본문을 훑어서 관련 페이지 찾기  
  → **단어 매칭**에 가깝고, “의미가 비슷한 문장”까지 찾는 건 아님.

### 지금 상태

- **이 방식은 켜져 있음**
- 분석할 때마다 위의 폴더들에서 마크다운을 읽어서 TF-IDF 인덱스를 만들고,  
  그걸로 근거를 찾아서 `evidence`에 붙입니다.  
→ 그래서 **“RAG용 데이터베이스를 아예 안 쓴다”는 말은 틀렸음**.  
  **마크다운 DB를 TF-IDF로 쓰는 RAG는 사용 중**입니다.

---

## 4. 방식 2: ChromaDB (벡터 DB) — 지금은 꺼져 있음

### 뭘 쓰나

- **데이터**: 위와 같은 마크다운이 아니라, **문장을 숫자 벡터로 바꾼 것**을 저장한 **벡터 DB(ChromaDB)**
- **검색 방식**:  
  검색어도 벡터로 바꾼 다음, “의미가 비슷한 벡터”를 찾는 방식  
  → **의미 유사도 검색** (단어가 똑같이 안 나와도 “비슷한 말”을 찾을 수 있음)

### 비유

- **데이터** = 책 내용을 “의미 요약 카드”로 만들어 둔 **별도 카드함(벡터 DB)**
- **검색** = 질문도 “의미 카드”로 바꾼 뒤, **그 카드와 가장 비슷한 카드**를 찾기  
  → **의미 기반 검색**

### 지금 상태

- **이 방식은 꺼져 있음**
- 코드에는 ChromaDB를 쓰는 경로가 있지만,  
  **환경변수 `RAG_USE_CHROMA=true`** 를 넣어야만 켜짐.
- 지금 `.env`에는 그게 없어서(기본값 false)  
  → **실제 벡터 DB(Chroma)는 전혀 안 쓰는 상태**입니다.

---

## 5. 정리 (처음에 한 말이 무슨 뜻인지)

| 말한 것 | 뜻 |
|--------|-----|
| “RAG용 데이터베이스를 **아예 미사용**은 아니다” | 마크다운 파일들(database/**, backend/guidelines/)을 **TF-IDF로 읽어서** 근거(evidence) 찾는 RAG는 **지금 돌아가고 있다**는 뜻. |
| “**마크다운 DB를 TF-IDF로 쓰는 RAG만 활성**” | 위처럼 **단어 빈도(TF-IDF)** 로 마크다운에서 문장을 찾는 방식만 켜져 있다는 뜻. |
| “**Chroma 같은 벡터 DB는 꺼져 있어서**, 실제 벡터 DB는 안 쓴다” | **의미 검색용 벡터 DB(Chroma)** 는 `RAG_USE_CHROMA=true`가 없어서 **사용하지 않는다**는 뜻. |

그래서:

- **쓰는 것**: 마크다운 파일 + TF-IDF 검색 → “RAG용 데이터(마크다운)”는 **사용 중**.
- **안 쓰는 것**: ChromaDB(벡터 DB) → **미사용**.

추가로 Chroma(벡터 검색)까지 쓰고 싶다면:  
`pip install chromadb sentence-transformers` 한 뒤, `.env`에 `RAG_USE_CHROMA=true` 를 넣으면 됩니다.
